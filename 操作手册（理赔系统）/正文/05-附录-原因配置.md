# 附录 A 原因配置

> 本附录为赔付原因（客户）与索赔原因（供应商）两张配置页的操作说明，被正文导入/新增任务引用。

---

两张配置页结构一致，都是给下游单据提供「原因」字典：**赔付原因**供客户赔付使用，**索赔原因**供供应商索赔（干线/尾程）使用。两套字典相互独立、不通用。导入或新增单据时提示原因不存在、或需要调整原因的归属时，到对应配置页维护。

## A.1 赔付原因（客户）配置页

**什么时候用**：导入/新增赔付单时提示赔付原因不存在；或需要新增、调整赔付原因及其分类归属。

**怎么做（导入）**：

1. 顶部【导入】，选择 .xlsx 文件；
2. 系统解析并弹出预览窗，逐行展示校验状态（绿色勾选=通过，红色叉号=失败，悬停显示失败原因）；
3. 预览窗按钮：【全部导入】（仅当存在校验通过记录时可用）、【下载模板】、【取消】；
4. 确认后执行导入。

模板字段：

| 字段 | 必填 | 取值要求 |
| --- | --- | --- |
| 各段分类 | 是 | A段 / B段 / C段 / D段 / BCD段 |
| 赔付类型 | 是 | 异常赔付 / KPI 扣罚 |
| 赔付原因 | 是 | 原因描述 |
| 索赔类型 | 否 | 如 丢件 / 延误出库 / 延误退件 |
| 责任划分 | 是 | 系统预设值：调度 / 操作 / 产品 / 客服 / 空运 / 关务 / IT / 尾程 / 海外转运 |
| 内外责任划分 | 是 | 内部 / 外部 |
| 备注 | 否 | 备注说明 |

校验规则：

| 校验项 | 不通过提示 |
| --- | --- |
| 文件格式 | 仅支持 .xlsx；「文件格式错误，请上传.xlsx文件」 |
| 必填非空 | 「第X行：[字段名]不能为空」 |
| 各段分类合法性 | 「第X行：各段分类值无效」 |
| 赔付类型合法性 | 「第X行：赔付类型值无效」 |
| 内外责任划分合法性 | 「第X行：内外责任划分值无效」 |
| 责任划分合法性 | 「第X行：责任划分值无效」 |
| 重复数据 | 同一赔付原因视为重复记录，**导入时执行更新**；「第X行：已存在，将执行更新」 |

**做完会怎样**：

- 全部成功：「导入成功，共导入X条记录」，刷新列表；
- 部分成功：「导入完成，成功X条，失败Y条」，可下载失败明细 Excel；
- 全部失败：「导入失败，所有记录均未通过校验」，显示失败原因汇总。

**页面内维护**：除导入外，列表行支持单行编辑与删除。

**注意**：重复原因执行的是**按原因名整行覆盖**——同一赔付原因再次导入时，模板里的各段分类、赔付类型、内外责任划分会直接替换旧值，不是跳过、也不是只补空字段。覆盖没有撤销入口，要改回只能回到列表逐行编辑。

## A.2 索赔原因（供应商）配置页

**什么时候用**：新增或导入干线索赔、尾程索赔时提示索赔原因不存在；或需要增补索赔原因。

**怎么做**：与 A.1 相同（顶部【导入】→ 选择 .xlsx → 预览校验 → 全部导入）。模板字段为三列：

| 字段 | 必填 | 取值要求 |
| --- | --- | --- |
| 各段分类 | 是 | A段 / B段 / C段 / D段 |
| 索赔类型 | 是 | 异常索赔 |
| 索赔原因 | 是 | 原因描述 |

校验与结果处理同 A.1：文件格式、必填非空、枚举合法性，同一索赔原因视为重复记录并**执行更新**（按原因名整行覆盖，见 A.1 注意）；导入结果为全部成功 / 部分成功（可下载失败明细）/ 全部失败。
