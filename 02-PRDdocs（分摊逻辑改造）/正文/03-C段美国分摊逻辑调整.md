# C段美国分摊逻辑调整 PRD

## 1. 需求说明

美国清关运单在分摊前，先将费用项归为两组，再分别分摊。除固定关税、欧盟清关处理费外，全部费用项归入「清关费」「清关费（票）」两组。

## 2. 适用范围

运单类型 = 国外清关，且目的节点的节点归属国家 = 美国。此范围外沿用现有 C段分摊逻辑。

## 3. 清关费的拆分

费用项为统一主数据，计算成本与实际成本共用同一套费用项。清关费一笔在计算成本侧按计费因子拆为三个费用项；账单侧为四个字段，其中清关费/HAWB 与清关费/包裹项映射到同一费用项。

| 类型 | 费用项编码 | 费用项 | 计费因子 | 账单费用项（编码） | 汇总费用项 |
| -- | -- | -- | -- | -- | -- |
| 原有 | CustomsClearanceCharge | 清关费 | 按主单数 | 清关费/MAWB（ClearanceMAWB） | 清关费 |
| 新增 | 待定 | 清关费（包裹项） | 按包裹数量 | 清关费/HAWB（ClearanceHAWB）、清关费/包裹项（ClearanceItem） | 清关费（票） |
| 新增 | 待定 | 清关费（核重） | 按重量 | 清关费/核重（ClearanceKg） | 清关费 |

拆分在计算成本生成侧完成，分摊侧只按费用项归组，不看计费因子。

**历史映射关系处理：在 cost → 其他功能 → 数据字典映射 中，原有四个账单费用项编码均映射到「清关费」，拆分后改为：**

- 清关费/MAWB（ClearanceMAWB）→ 清关费（CustomsClearanceCharge）
- 清关费/HAWB（ClearanceHAWB）→ 清关费（包裹项）
- 清关费/包裹项（ClearanceItem）→ 清关费（包裹项）
- 清关费/核重（ClearanceKg）→ 清关费（核重）

该映射关系以直接改库方式调整。

## 4. 归组与分摊

| 汇总费用项  | 组内费用项                 | 运单 → 箱子  | 箱子 → 包裹 |
| ------ | --------------------- | -------- | ------- |
| 清关费    | 清关费、清关费（核重）、13 项普通费用项 | 箱子重量占比   | 包裹计费重占比 |
| 清关费（票） | 清关费（包裹项）、税费           | 箱内包裹数量占比 | 箱内包裹均分  |

清关费分摊公式：

```
箱子分摊额 = 运单清关费金额 × (本箱子重量 ÷ 运单下全部箱子重量之和)
包裹分摊额 = 箱子分摊额 × (本包裹计费重 ÷ 箱内全部包裹计费重之和)
```

清关费（票）分摊公式：

```
箱子分摊额 = 运单清关费（票）金额 × (箱内包裹数量 ÷ 运单下全部包裹数量)
包裹分摊额 = 箱子分摊额 ÷ 箱内包裹数量
```

固定关税、欧盟清关处理费按原有逻辑分摊，本次不改。

各费用项归入哪一组，见第 6 节。

## 5. 通用约定

- 汇总维度：沿用现有逻辑按「运单Id + 一级费用 + 币种」分组；本次在此基础上按汇总费用项分成「清关费」「清关费（票）」两笔，分别进入分摊。计算成本分摊取计算币种，实际成本分摊取实际币种。
- 分摊场景：计算成本分摊与实际成本分摊共用同一套规则，仅金额来源不同。
- 原费用项追溯：汇总后不保留来源费用项拆分关系；固定关税、欧盟清关处理费为独立费用项，不受影响。
