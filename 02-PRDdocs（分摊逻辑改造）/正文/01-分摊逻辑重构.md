# 分摊逻辑重构 PRD

## 1. 需求说明

现行费用项处理为硬编码：除指定特殊费用项外，其余费用项全部汇总成一个费用项，再按固定顺序依次执行全部分摊逻辑。各分摊因子也各自有代码实现。

本需求改为配置驱动：由配置表定义哪些原始费用项汇总成哪个汇总费用项、用哪些分摊因子分摊，不再依赖固定顺序与硬编码。分摊因子逻辑保持为外置计算规则，新增分摊因子以插入式实现，不改动分摊主流程。

本次重构覆盖现有全部成本段、全部国家的费用项分摊，原有规则全部迁入配置表，不留未配置的例外。

## 2. 配置表结构

| 字段 | 存储值 | 是否多值 | 含义 |
| --- | --- | --- | --- |
| 成本段 | 运单类型编码 | 单值 | 运单类型 |
| 国家 | 国家编码 | 可多值、可留空 | 运单目的节点所属国家；留空表示适用全部国家（兜底） |
| 汇总费用项 | 费用项编码 | 单值 | 分摊前要汇总成的目标费用项 |
| 原始费用项 | 费用项编码 | 可多值 | 汇总到该汇总费用项的来源费用项 |
| 分摊因子 | 分摊因子代码 | 可多值、有序 | 按优先级排列，取第一个满足的 |

原始费用项是运单上已存在的费用项（计算成本生成或账单同步而来）；汇总费用项是归组后实际参与分摊的对象。

**多值规则**

- 国家、原始费用项为无序集合。国家支持多值，是因为欧盟等区域包含多个国家，同一套规则若按单国家逐条配置会产生大量重复行；允许多值后可一次覆盖一组国家。
- 分摊因子为有序集合，从左到右即优先级，逐个判断是否满足，第一个满足的生效，全部不满足则报错。

**存储口径**

配置表存储费用项编码，不存名称。配置界面按名称下拉选择，选中后落库为编码；费用项名称变更不影响已有配置。匹配与汇总按编码执行，名称仅用于界面展示。

## 3. 配置校验

| 校验项 | 规则 |
| --- | --- |
| 必填 | 成本段、汇总费用项必填；原始费用项、分摊因子各至少填一个值；国家可留空 |
| 费用项归属 | 汇总费用项、原始费用项必须属于所选成本段，不属于则该行不允许保存 |
| 唯一性 | 同一成本段、同一国家下，一个原始费用项只能归属一个汇总费用项；填了多个国家的行，按国家展开后逐一比对 |
| 因子一致性 | 同一成本段、同一国家、同一汇总费用项下，分摊因子必须一致；不一致不允许保存 |
| 分摊因子有效性 | 填写的分摊因子必须存在，同一行内不得重复 |
| 国家有效性 | 非空时须为有效国家编码 |

校验在保存时执行，任一不通过即阻断保存并提示冲突项。

## 4. 汇总

- 汇总维度：运单Id + 一级费用 + 币种 + 汇总费用项。计算成本分摊取计算币种，实际成本分摊取实际币种，两者分别执行，不混用。
- 映射到同一汇总费用项、但一级费用不同的，拆成两笔独立分摊。
- 主附赔是运单汇总环节的既有维度，由运单汇总处理逻辑处理；配置表不配置该维度，只定义费用项归组与分摊因子。

## 5. 配置匹配与执行

### 5.1 匹配

分摊按运单逐票执行，每票开始时读取一次配置，票内使用同一份。

匹配键为 成本段 + 国家 + 原始费用项，按以下顺序：

1. 成本段 + 运单目的节点所属国家 + 原始费用项
2. 未命中 → 成本段 + 国家为空 + 原始费用项
3. 仍未命中 → 该运单分摊失败，记录失败原因

约束：同一成本段、同一国家下，一个原始费用项只能归属一个汇总费用项，不得同时归属多个。同一成本段、同一国家、同一汇总费用项下，分摊因子唯一。不同国家（含国家为空）可以各自配置，互不影响。

运单上的原始费用项全部匹配成功后，才执行分摊；任一未匹配，该运单停止分摊。

### 5.2 执行顺序

1. 按 5.1 完成运单上全部原始费用项的匹配，得到「原始费用项 → 汇总费用项」的对应关系。
2. 按 运单Id + 一级费用 + 币种 + 汇总费用项 聚合金额，每个组合形成一笔待分摊金额；币种按当前分摊场景取计算币种或实际币种。
3. 对每一笔待分摊金额依次执行：
   - 按该汇总费用项配置的分摊因子顺序逐个判断，取第一个满足的，作为本笔的生效因子。
   - 按生效因子的规则，将金额分摊到箱子。
   - 按生效因子对应的规则，将箱子金额分摊到包裹。
4. 任一步骤失败，该运单整体不产生分摊结果。

第 3 步对所有金额一律执行，金额为 0 或为负时不跳过、不做特殊处理。

## 6. 分摊规则

### 6.1 用什么分摊因子

- 运单 → 箱子：用配置表「分摊因子」列配置的分摊因子，按顺序逐个判断，第一个满足的生效。
- 箱子 → 包裹：基于运单 → 箱子所用的生效因子判断，不重新取分摊因子。包裹数量、V1V2、空运分摊重量沿用该因子；箱子重量、箱子CBM 改用包裹计费重。

### 6.2 每种分摊因子怎么分摊

| 分摊因子编码 | 分摊因子 | 运单 → 箱子 | 箱子 → 包裹 |
| --- | --- | --- | --- |
|  | 箱子重量 | 按箱子重量占比 | 按包裹计费重占比 |
|  | 箱子CBM | 按箱子CBM 占比 | 按包裹计费重占比 |
|  | 包裹数量 | 按箱内包裹数占比 | 箱内包裹均分 |
|  | V1V2 | V1 按 SKU 行数、V2 按包裹数 | V1 按 SKU 行数、V2 按包裹数 |
|  | 空运分摊重量 | 按箱子空运分摊重量占比 | 按包裹空运分摊重量占比 |

## 7. 分摊因子

- 判定条件与计算逻辑内置于分摊因子自身，配置只引用分摊因子。
- 分摊因子支持插入式新增，不改动分摊主流程。
- 配置多个分摊因子时按顺序逐个判断，第一个满足的生效，全部不满足则报错。
- 零重箱、箱子CBM 阈值（0.001）等校验属于分摊因子自身的满足条件。
- 首批分摊因子：箱子重量、箱子CBM、包裹数量、V1V2、空运分摊重量。

## 8. 生效与重算

- 配置即时生效，分摊时取当时配置，结果固化。
- 配置变更不自动回溯已分摊结果。
- 需要时人工重新分摊，属主动重算，按重跑时的配置执行。

## 9. 计算成本与实际成本

共用同一份配置。计算成本分摊取计算币种与计算成本金额，实际成本分摊取实际币种与账单回写金额，两者分别执行。
