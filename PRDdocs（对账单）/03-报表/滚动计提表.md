# 滚动计提表

## 一、功能概述

### 1.1 业务背景

滚动计提表用于每月会计期末，查询出具当期成本计提入账数据。支持**计提确认**功能：财务确认后当期数据固化，历史查询结果不变，满足财务合规要求。基于对账明细底表`完成对账时间`字段做历史回溯，计提期间的查询结果规则如下：

- **确认**（计提类型=确认）：该计提期间内完成结算的记录，按`付款金额`入账，结果凝固不变
- **暂估**（计提类型=暂估）：业务发生在该计提期间或之前、截至期末仍未完成对账结算的记录（判定条件：`业务期间` ≤ 计提期间，且 `完成对账时间` 为空或所在月 > 计提期间），按`最新计算金额`入账（取查询时刻的实时值，可能随成本波动变化），业务期间（`单据时间`所在月）以 YYYY-MM 字段值直接体现当期/往期归属，财务自行筛选

> **时间说明**：会计实务中通常是 N 月做 N-1 月的账。例如 7 月操作，计提期间 = 2026-06（做 6 月账）。文档中"计提期间"指会计上的目标月份，不等于实际操作的日历月份。
>
> **历史可复现**：已确认计提期间数据固化不变，历史查询结果可重现；未确认计提期间仅暂估数据实时变化（确认数据因`完成对账时间`为静态回写字段而凝固不变），可能随单据成本更新波动。

### 1.2 核心公式

```
当期成本计提 = 当期确认金额 + 各期暂估合计（当期入账金额）
```

- **当期确认金额**：已确认期间 → 读计提确认表固化值；未确认期间 → 对账明细底表`完成对账时间`所在月 = 计提期间 的记录，取`付款金额`合计
- **各期暂估合计**：已确认期间 → 读计提确认表固化值；未确认期间 → 对账明细底表`完成对账时间`所在月 > 计提期间 或 `完成对账时间`为空 且 `业务期间 ≤ 计提期间` 的记录（含当期和往期未结算），取`最新计算金额`合计

## 二、数据来源与取数规则

报表根据计提期间状态动态选择数据源：已确认期间读取**计提确认表**（固化数据），未确认期间实时查询**对账明细底表**聚合生成。

### 2.1 报表取数字段清单

| 报表列 / 筛选项   | 底表字段                           | 补充说明                                                                                                                            |
| ----------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 计提期间          | 用户选择参数（比对`完成对账时间`） | YYYY-MM，目标会计月；确认行`完成对账时间`所在月=计提期间，暂估行`完成对账时间`所在月>计提期间或为空且`业务期间≤计提期间`（详见4.1） |
| 供应商编码 / 名称 | `供应商编码`、`供应商名称`         | —                                                                                                                                   |
| 账单类型          | `账单类型`                         | —                                                                                                                                   |
| 费用项            | `费用项`                           | 费用项                                                                                                                              |
| 业务期间          | `单据时间`所属整月                 | 取值规则见2.2                                                                                                                       |
| 币种              | `币种`                             | —                                                                                                                                   |
| 金额（确认）  | `付款金额`                         |                                                                                                                                     |
| 金额（暂估）  | `最新计算金额`                     | 取查询时刻最新值                                                                                                                    |

### 2.2 关键取值规则

**1）单据时间取值规则**（用于计算业务期间）：

- **非尾程类**（国内转运 / 内地空运 / 香港空运 / 空运卡转 / 国外清关 / 国外转运）→ 运单**发运时间**，发运时间为空则取运单**创建时间**
- **尾程类**（尾程派送）→ 订单**出库时间**，出库时间为空则取订单**创建时间**
- **孤儿账单** → 底表**创建时间**

**2）供应商取值规则**：

- 统一取底表`供应商编码`、`供应商名称`字段

**3）币种与金额口径**：

- 全表金额均不做跨币种折算或累加
- 暂估取`最新计算金额`，该值实时更新不受锁定限制。**每次查询时取当前时刻的实时值**。

## 三、统计维度

| 维度     | 字段                       | 说明                                                                                                                                                                                                      |
| -------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 计提期间 | 用户选择参数（非底表字段） | YYYY-MM，目标会计月；用于筛选报表范围、分组汇总维度；与底表`完成对账时间`比对判定计提类型：确认行`完成对账时间`所在月=计提期间，暂估行`完成对账时间`所在月>计提期间或为空且`业务期间≤计提期间`（详见4.1） |
| 供应商   | 供应商编码、供应商名称     | 取底表`供应商编码`、`供应商名称`字段（详见2.2）                                                                                                                                                          |
| 账单类型 | 账单类型                   | 7 个枚举：国内转运 / 内地空运 / 香港空运 / 空运卡转 / 国外清关 / 国外转运 / 尾程派送                                                                                                                      |
| 计提类型 | 计提类型                   | 2 个枚举：确认 / 暂估（按 4.1 判定规则）                                                                                                                                                                  |
| 业务期间 | 单据时间所属整月           | YYYY-MM，取值规则见2.2；与计提期间大小关系决定当期/往期归属                                                                                                                                               |
| 费用项   | 费用项                     | 系统固定枚举，与账单类型为父子关系，同一账单类型下可有多个费用项                                                                                                                                          |
| 币种     | 币种                       | 取值来源：对账明细底表`币种`字段；不同币种分行展示，不做跨币种折算或累加                                                                                                                                    |

### 3.1 两个时间概念

| 概念         | 定义                                                 | 用途                                                                                         |
| ------------ | ---------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **计提期间** | 目标会计月（做账月份）                               | 筛选报表范围、分组汇总维度                                                                   |
| **业务期间** | 业务发生所在月 = `单据时间`所属整月（取值规则见2.2） | 直接以 YYYY-MM 字段值展示，财务可按「业务期间 vs 计提期间」的大小关系，自行筛选当期/往期归属 |

> 例：7 月做 6 月账 → 计提期间 = 2026-06。业务期间 = 2026-06 → 归属「当期」；= 2026-05 → 归属「1 月前」，依此类推。
>
> **准入规则**：报表准入分两层过滤——**第一层按`完成对账时间`**：`完成对账时间所在月= M`→确认（进报表）；`完成对账时间所在月< M`→硬过滤不进报表（场景③）；`完成对账时间所在月> M`或为空→进入暂估候选池。**第二层按`业务期间`**：暂估候选中`≤ M`→暂估进报表（场景②）；`> M`→不进报表（场景④）。进报表后，业务期间再以YYYY-MM字段值体现当期/往期展示归属。

## 四、滚动计提判定逻辑

### 4.1 判定规则（按计提期间 M 查询）

分两层定义：先定义两种计提类型的取数口径，再用全场景矩阵把对账明细底表所有可能的字段组合穷举覆盖，无遗漏。

#### 4.1.1 计提类型定义

报表输出只有「确认」和「暂估」两种计提类型，范围和取值如下：

> **数据来源规则**：选择计提期间M后，系统判断M期的状态并读取对应数据：
>
> - M期已确认 → 读取M期计提确认表的固化数据（金额为确认时刻的固化值）
> - M期未确认 → 读取对账明细底表的实时数据（金额为查询时刻的实时值）

| 计提类型 | 范围条件（全部满足）                                                       | 取值字段               | 业务期间归属                                       |
| -------- | -------------------------------------------------------------------------- | ---------------------- | -------------------------------------------------- |
| **确认** | `完成对账时间`所在月 = M                                                   | `付款金额`         | = `单据时间`整月（YYYY-MM），直接体现当期/往期归属 |
| **暂估** | (`完成对账时间`所在月 > M **或** `完成对账时间`为空) **且** `业务期间 ≤ M` | `最新计算金额`（空值视为0参与计算） | = `单据时间`整月（YYYY-MM），直接体现当期/往期归属 |

#### 4.1.2 全场景覆盖矩阵（所有组合无遗漏）

对对账明细底表任一条记录，按「`完成对账时间`所在月 × `业务期间`」可落到以下 4 种场景之一，覆盖所有可能，无需额外猜：

| 场景 | `完成对账时间`所在月（对账明细底表字段值） | `业务期间`（= `单据时间`整月） | M 期归属            | 业务含义                                                                   |
| ---- | ------------------------------------------ | ------------------------------ | ------------------- | -------------------------------------------------------------------------- |
| ①    | `所在月= M`                                | 任意值（通常 ≤ M）             | **确认**            | M 期内完成结算的记录，按实际付款金额入账                                   |
| ②    | `所在月> M` **或** `为空`                  | `≤ M`                          | **暂估**            | 业务发生在 M 期或之前、截至 M 期末仍未完成对账结算，按最新计算金额暂估入账 |
| ③    | `所在月< M`                                | 任意值                         | **不进入 M 期报表** | 已在 M 之前的某个期间确认并出表，无需再处理                                |
| ④    | `所在月> M` **或** `为空`                  | `> M`                          | **不进入 M 期报表** | 业务发生时间（单据时间）在 M 之后，当期不应预提                            |

> **清账 / 不支付**：无特殊分支，按上表 4 场景正常归入即可。因`付款金额 = 0`，归入场景①确认时金额为 0，不影响合计；归入场景②时参与暂估（真实还原历史状态）。

> **判定互斥性**：对任一计提期间M，任一条记录在4场景中只会落入其中一种——进报表的场景①②中**确认/暂估互斥不重复**（`完成对账时间`所在月=M 归确认，`完成对账时间`所在月>M 或空归暂估，两者不会同时满足）；不进报表的场景③④自然排除。

### 4.3 示例

> 按计提期间=4月、5月、6月分别推演。**本例假设供应商=S001顺丰**；账单类型 国内转运，币种 CNY。

**计提期间 2026-04**：

| 计提期间 | 供应商编码 | 供应商名称 | 账单类型 | 计提类型 | 业务期间 | 费用项 | 币种 | 金额           |
| -------- | ---------- | ---------- | -------- | -------- | -------- | ------ | ---- | -------------- |
| 2026-04  | S001       | 顺丰       | 国内转运 | 确认     | 2026-04  | 运费   | CNY  | 65（当期业务） |
| 2026-04  | S001       | 顺丰       | 国内转运 | 暂估     | 2026-04  | 运费   | CNY  | 40（当期业务） |

> 💡 跨期对照提示（对比4月示例）：4月暂估 40 里，35 已在 5 月完成结算（转确认），剩余 5 截至 5 月末仍未结算，计入5月暂估。

| -------- | ---------- | ---------- | -------- | -------- | -------- | ------ | ---- | ----------------------- |
| 2026-05  | S001       | 顺丰       | 国内转运 | 确认     | 2026-05  | 运费   | CNY  | 70（当期业务）          |
| 2026-05  | S001       | 顺丰       | 国内转运 | 确认     | 2026-04  | 运费   | CNY  | 35（往期业务·当期结算） |
| 2026-05  | S001       | 顺丰       | 国内转运 | 暂估     | 2026-05  | 运费   | CNY  | 30（当期业务）          |
| 2026-05  | S001       | 顺丰       | 国内转运 | 暂估     | 2026-04  | 运费   | CNY  | 5（往期未结）           |

> 财务自行聚合：确认合计=70+35=100，暂估合计=30+5=35，成本计提总计=100+35=**135**
> 当期/往期拆分一眼可读：业务期间=2026-05 是当期，=2026-04 是 1 月前往期

> 统计粒度：前 7 列（计提期间 + 供应商编码/名称 + 账单类型 + 计提类型 + 业务期间 + 费用项 + 币种）是 GROUP BY 的完整维度，第 8 列是聚合值。**特别说明**：
>
> - 数据来源：按查询期间状态自动切换——已确认期间读计提确认表（固化数据）；未确认期间读对账明细底表（实时数据）。
> - 供应商取值：统一取底表`供应商编码`、`供应商名称`字段。
>
> 财务使用建议：先按计提类型=确认/暂估筛开，再按供应商、账单类型、业务期间任意维度加总入账。

### 5.4 计提确认操作

点击"确认计提"后，系统将该计提期间的完整报表数据全量写入计提确认表固化，固化后数据与底表解耦，后续查询直接读取固化数据。

- **触发条件**：仅对"未确认"的计提期间开放
- **二次确认**：点击按钮后弹出确认对话框，提示：
  ```
  ⚠️ 确认后将固化当期计提数据，操作不可逆！
  - 已确认期间不可撤销、不可重新确认
  - 如需调整金额，请在金蝶系统通过冲销处理
  - 请仔细核对数据后谨慎操作
  ```
  对话框提供"确认"和"取消"按钮，点击"确认"执行固化操作，点击"取消"关闭对话框不执行任何操作
- **不可逆性**：已确认期间不可撤销、不可重新确认。如需调整金额，由财务在金蝶系统通过冲销处理，本系统不支持此操作。
