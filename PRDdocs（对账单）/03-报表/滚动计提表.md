# 滚动计提表

## 一、功能概述

### 1.1 业务背景

滚动计提表用于每月会计期末，查询出具当期成本计提入账数据。基于对账明细底表`会计期间`字段做历史回溯，计提期间的查询结果规则如下：

- **确认**（计提类型=确认）：该计提期间内完成结算的记录，按`付款金额`入账，结果凝固不变
- **暂估**（计提类型=暂估）：业务发生在该计提期间或之前、截至期末仍未完成对账结算的记录（判定条件：`业务期间` ≤ 计提期间，且 `会计期间` 为空或 > 计提期间），按`最新计算金额`入账（取查询时刻的实时值，可能随成本波动变化），业务期间（`单据时间`所在月）以 YYYY-MM 字段值直接体现当期/往期归属，财务自行筛选

> **时间说明**：会计实务中通常是 N 月做 N-1 月的账。例如 7 月操作，计提期间 = 2026-06（做 6 月账）。文档中"计提期间"指会计上的目标月份，不等于实际操作的日历月份。
>
> **历史可复现**：确认部分结果凝固不变（因会计期间为静态回写字段）；暂估部分取查询时刻的`最新计算金额`实时值，可能随单据成本更新波动。财务按当期计提结果入账，下期计提时冲销上期暂估（由财务在金蝶系统自行处理），本系统仅出当期成本计提入账数据。

### 1.2 核心公式

```
成本计提 = 确认金额 + 各期暂估合计（当期入账金额）
```

- **确认金额**：对账明细底表`会计期间 = 计提期间`的记录，取`付款金额`（原币）合计，业务期间以 YYYY-MM 字段值体现当期/往期归属
- **暂估金额**：对账明细底表`会计期间 > 计提期间`或`会计期间 为空`且`业务期间 ≤ 计提期间`的记录，取`最新计算金额`（原币）合计，业务期间以 YYYY-MM 字段值体现当期/往期归属

## 二、数据来源与取数规则

报表直接实时查询**对账明细底表**聚合生成，不写中间表，无需关联其他表。

### 2.1 报表取数字段清单

| 报表列 / 筛选项             | 底表字段                           | 底表字段号 | 补充说明               |
| --------------------------- | ---------------------------------- | ---------- | ---------------------- |
| 计提期间                    | `会计期间`                         | 14         | YYYY-MM                |
| 供应商编码 / 名称（确认行） | `实际供应商编码`、`实际供应商名称` | 17、18     | —                      |
| 供应商编码 / 名称（暂估行） | `系统供应商编码`、`系统供应商名称` | 15、16     | —                      |
| 账单类型                    | `账单类型`                         | 19         | —                      |
| 业务期间                    | `单据时间`所属整月                 | 20         | 取值规则见2.2          |
| 币种                        | `币种`                             | 6          | —                      |
| 原币金额（确认）            | `付款金额`                         | 12         | 原币                   |
| 原币金额（暂估）            | `最新计算金额`                     | 8          | 原币，取查询时刻最新值 |

### 2.2 关键取值规则

**1）单据时间取值规则**（底表字段20，用于计算业务期间）：

- **非尾程类**（国内转运 / 内地空运 / 香港空运 / 空运卡转 / 国外清关 / 国外转运）→ 运单**发运时间**，发运时间为空则取运单**创建时间**
- **尾程类**（尾程派送）→ 订单**出库时间**，出库时间为空则取订单**创建时间**
- **孤儿账单** → 底表**创建时间**（底表字段13）

**2）供应商动态取值规则**：

- 计提类型=确认 → 取`实际供应商编码`、`实际供应商名称`
- 计提类型=暂估 → 取`系统供应商编码`、`系统供应商名称`

**3）币种与金额口径**：

- 全表金额均为**原币**，不做跨币种折算或累加
- 暂估取`最新计算金额`，该值实时更新不受锁定限制，报表查询时取当前值

## 三、统计维度

| 维度     | 字段                   | 说明                                                                                                                        |
| -------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 计提期间 | 会计期间               | YYYY-MM，查询统计的目标会计期间                                                                                             |
| 供应商   | 供应商编码、供应商名称 | 动态取值：计提类型=确认 → `实际供应商编码`、`实际供应商名称`；计提类型=暂估 → `系统供应商编码`、`系统供应商名称`（详见2.2） |
| 账单类型 | 账单类型名称           | 7 个枚举：国内转运 / 内地空运 / 香港空运 / 空运卡转 / 国外清关 / 国外转运 / 尾程派送                                        |
| 币种     | 原币                   | 所有金额为原币，不做折算                                                                                                    |

### 3.1 两个时间概念

| 概念         | 定义                                                 | 用途                                                                                         |
| ------------ | ---------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **计提期间** | 目标会计月（做账月份）                               | 筛选报表范围、分组汇总维度                                                                   |
| **业务期间** | 业务发生所在月 = `单据时间`所属整月（取值规则见2.2） | 直接以 YYYY-MM 字段值展示，财务可按「业务期间 vs 计提期间」的大小关系，自行筛选当期/往期归属 |

> 例：7 月做 6 月账 → 计提期间 = 2026-06。业务期间 = 2026-06 → 归属「当期」；= 2026-05 → 归属「1 月前」，依此类推。
>
> **职责边界（不混淆）**：报表准入分两层过滤——**第一层按`会计期间`**：`= M`→确认（进报表）；`< M`→硬过滤不进报表（场景③）；`> M`或为空→进入暂估候选池。**第二层按`业务期间`**：暂估候选中`≤ M`→暂估进报表（场景②）；`> M`→不进报表（场景④）。进报表后，业务期间再以YYYY-MM字段值体现当期/往期展示归属。

## 四、滚动计提判定逻辑

### 4.1 判定规则（按计提期间 M 查询）

分两层定义：先定义两种计提类型的取数口径，再用全场景矩阵把对账明细底表所有可能的字段组合穷举覆盖，无遗漏。

#### 4.1.1 计提类型定义

报表输出只有「确认」和「暂估」两种计提类型，范围和取值如下：

| 计提类型 | 范围条件（全部满足）                                          | 取值字段               | 业务期间归属                                       |
| -------- | ------------------------------------------------------------- | ---------------------- | -------------------------------------------------- |
| **确认** | `会计期间 = M`                                                | `付款金额`（原币）     | = `单据时间`整月（YYYY-MM），直接体现当期/往期归属 |
| **暂估** | (`会计期间 > M` **或** `会计期间 为空`) **且** `业务期间 ≤ M` | `最新计算金额`（原币） | = `单据时间`整月（YYYY-MM），直接体现当期/往期归属 |

#### 4.1.2 全场景覆盖矩阵（所有组合无遗漏）

对对账明细底表任一条记录，按「`会计期间` × `业务期间`」可落到以下 4 种场景之一，覆盖所有可能，无需额外猜：

| 场景 | `会计期间`（对账明细底表字段值） | `业务期间`（= `单据时间`整月） | M 期归属            | 业务含义                                                                   |
| ---- | -------------------------------- | ------------------------------ | ------------------- | -------------------------------------------------------------------------- |
| ①    | `= M`                            | 任意值（通常 ≤ M）             | **确认**            | M 期内完成结算的记录，按实际付款金额入账                                   |
| ②    | `> M` **或** `为空`              | `≤ M`                          | **暂估**            | 业务发生在 M 期或之前、截至 M 期末仍未完成对账结算，按最新计算金额暂估入账 |
| ③    | `< M`                            | 任意值                         | **不进入 M 期报表** | 已在 M 之前的某个期间确认并出表，无需再处理                                |
| ④    | `> M` **或** `为空`              | `> M`                          | **不进入 M 期报表** | 业务发生时间（单据时间）在 M 之后，当期不应预提                            |

> **清账 / 不支付**：无特殊分支，按上表 4 场景正常归入即可。因`付款金额 = 0`，归入场景①确认时金额为 0，不影响合计；归入场景②时参与暂估（真实还原历史状态）。

> **判定互斥性**：对任一计提期间M，任一条记录在4场景中只会落入其中一种——进报表的场景①②中**确认/暂估互斥不重复**（`会计期间=M`归确认，`会计期间>M`或空归暂估，两者不会同时满足）；不进报表的场景③④自然排除。

### 4.3 示例

> 以下按计提期间=4月、5月、6月分别推演。**本例简化假设系统供应商=实际供应商=S001顺丰**（两者业务上可不同，确认时按实际供应商结转即可）；账单类型 国内转运，币种 CNY。

**计提期间 2026-04**：

| 计提期间 | 供应商编码 | 供应商名称 | 账单类型 | 计提类型 | 业务期间 | 币种 | 原币金额       |
| -------- | ---------- | ---------- | -------- | -------- | -------- | ---- | -------------- |
| 2026-04  | S001       | 顺丰       | 国内转运 | 确认     | 2026-04  | CNY  | 65（当期业务） |
| 2026-04  | S001       | 顺丰       | 国内转运 | 暂估     | 2026-04  | CNY  | 40（当期业务） |

> 财务自行聚合：确认合计=65，暂估合计=40，成本计提总计=65+40=**105**

**计提期间 2026-05**：

> 💡 跨期对照提示（对比4月示例）：4月暂估 40 里，35 已在 5 月完成结算（转确认），剩余 5 截至 5 月末仍未结算，继续暂估。

| 计提期间 | 供应商编码 | 供应商名称 | 账单类型 | 计提类型 | 业务期间 | 币种 | 原币金额                |
| -------- | ---------- | ---------- | -------- | -------- | -------- | ---- | ----------------------- |
| 2026-05  | S001       | 顺丰       | 国内转运 | 确认     | 2026-05  | CNY  | 70（当期业务）          |
| 2026-05  | S001       | 顺丰       | 国内转运 | 确认     | 2026-04  | CNY  | 35（往期业务·当期结算） |
| 2026-05  | S001       | 顺丰       | 国内转运 | 暂估     | 2026-05  | CNY  | 30（当期业务）          |
| 2026-05  | S001       | 顺丰       | 国内转运 | 暂估     | 2026-04  | CNY  | 5（往期未结）           |

> 财务自行聚合：确认合计=70+35=100，暂估合计=30+5=35，成本计提总计=100+35=**135**
> 当期/往期拆分一眼可读：业务期间=2026-05 是当期，=2026-04 是 1 月前往期

**计提期间 2026-06**：

> 💡 跨期对照提示（对比5月示例）：5月暂估 30 里，30 已在 6 月完成结算（5月业务当期结算完成），5（4月暂估剩余）截至 6 月末仍未结算，继续暂估。

| 计提期间 | 供应商编码 | 供应商名称 | 账单类型 | 计提类型 | 业务期间 | 币种 | 原币金额                |
| -------- | ---------- | ---------- | -------- | -------- | -------- | ---- | ----------------------- |
| 2026-06  | S001       | 顺丰       | 国内转运 | 确认     | 2026-06  | CNY  | 60（当期业务）          |
| 2026-06  | S001       | 顺丰       | 国内转运 | 确认     | 2026-05  | CNY  | 30（往期业务·当期结算） |
| 2026-06  | S001       | 顺丰       | 国内转运 | 暂估     | 2026-06  | CNY  | 40（当期业务）          |
| 2026-06  | S001       | 顺丰       | 国内转运 | 暂估     | 2026-05  | CNY  | 5（往期未结）           |

> 财务自行聚合：确认合计=60+30=100，暂估合计=40+5=45，成本计提总计=100+45=**145**
> 往期业务当期结算一目了然：2026-06 的确认金额里，30 是 2026-05 月发生的业务在 6 月才完成结算

## 五、页面布局

### 5.1 筛选条件

| 字段名称 | 类型                        | 必填   | 说明                                                                                                                     |
| -------- | --------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------ |
| 计提期间 | 下拉选择（`会计期间`枚举）  | **是** | 默认最新可用`会计期间`的上一期（会计常规），支持选择历史期间                                                             |
| 供应商   | 下拉选择（按编码+名称匹配） | 否     | 按供应商维度筛选。筛选逻辑：计提类型=确认的行按`实际供应商`匹配；计提类型=暂估的行按`系统供应商`匹配（分别匹配后取并集） |
| 账单类型 | 下拉选择                    | 否     | 按账单类型筛选                                                                                                           |
| 币种     | 下拉选择                    | 否     | 按币种筛选                                                                                                               |

### 5.2 操作按钮

| 按钮 | 功能                                     | 前置条件     |
| ---- | ---------------------------------------- | ------------ |
| 查询 | 根据筛选条件直接查对账明细底表聚合出报表 | 计提期间必选 |
| 重置 | 清空筛选条件                             | 无           |
| 导出 | 导出当前报表（Excel）                    | 已有查询结果 |

### 5.3 报表展示

按 7 个维度聚合出一行数据，8 列扁平结构直出给财务，财务自行筛选透视按需要维度入账：

| 列         | 说明                                                                                                     |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| 计提期间   | 对账明细底表`会计期间`（YYYY-MM），完成对账时回写静态值，必选筛选一致                                    |
| 供应商编码 | 动态取值详见2.2                                                                                          |
| 供应商名称 | 动态取值详见2.2                                                                                          |
| 账单类型   | 7 个枚举：国内转运 / 内地空运 / 香港空运 / 空运卡转 / 国外清关 / 国外转运 / 尾程派送                     |
| 计提类型   | `确认` 或 `暂估`（按 4.1 判定规则）                                                                      |
| 业务期间   | `单据时间`所属整月（YYYY-MM），取值规则见2.2。与计提期间大小关系决定归属：=计提期间→当期；<计提期间→往期 |
| 币种       | 原币币种，不做跨币种折算或累加                                                                           |
| 原币金额   | 计提类型=确认 → `付款金额`合计；计提类型=暂估 → `最新计算金额`合计                                       |

> 统计粒度：前 7 列（计提期间 + 供应商编码/名称 + 账单类型 + 计提类型 + 业务期间 + 币种）是 GROUP BY 的完整维度，第 8 列是聚合值。**特别说明**：
> 同一笔业务暂估期间可能记在A供应商名下，确认期间会结转到B供应商名下——这是业务上有意为之的：每期都会全量冲销上期暂估再入当期，实际成本必须挂到正确的实际供应商头上。
>
> 财务使用建议：先按计提类型=确认/暂估筛开，再按供应商、账单类型、业务期间任意维度加总入账。
