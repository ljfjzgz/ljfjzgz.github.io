# 应付账单统计表

## 一、功能概述

### 1.1 业务背景

每月财务/业务管理人员扫描结算进度的管理表，用于跟进未结算账单处理、掌握应付账款整体状况。按**供应商 + 账单类型 + 业务期间 + 币种** 4个维度统计，分三类展示金额分布：已结算金额（计算）、未结算金额（计算）、不结算金额（计算）。

> **核心说明**：报表直接读取对账明细底表的最新状态，反映查询时刻的实时结算进度。底表中`最新计算金额`为空的记录，在报表统计时按 0 处理，确保总金额等式成立。

### 1.2 核心公式

**总金额（计算） = 已结算金额（计算） + 未结算金额（计算） + 不结算金额（计算）**

> 三类判定互斥且全覆盖，等式严格成立。

---

## 二、数据来源与字段口径映射

报表基于**对账明细底表**聚合，反映查询时刻最新结算状态。所有统计维度与金额字段均已在底表中冗余记录，报表直接查询底表即可。同一业务期间的查询结果可能随结算状态更新而变化（非凝固历史快照）。

### 2.1 字段来源映射表

| 报表列 / 筛选项                   | 取值来源表   | 取值字段                   |
| --------------------------------- | ------------ | -------------------------- |
| 供应商编码 / 名称                 | 对账明细底表 | `供应商编码`、`供应商名称` |
| 账单类型                          | 对账明细底表 | `账单类型`                 |
| 业务期间（单据时间整月）          | 对账明细底表 | 由 `单据时间` 派生         |
| 币种                              | 对账明细底表 | `币种`                     |
| 总金额 / 已 / 未 / 不结算（计算） | 对账明细底表 | `最新计算金额`             |
| 结算状态判定                      | 对账明细底表 | `结算策略`、`明细状态`、`作废标记` |

### 2.2 结算状态三方判定

**全局过滤**：所有类别均**排除作废追加记录 R'**（即排除 `作废标记 = 作废` 且 `明细状态 = 已完成` 的记录，R' 仅用于底表查询追溯）。

> 对账中阶段被标记作废但未完成对账的记录（`作废标记 = 作废` 且 `明细状态 ≠ 已完成`，即原占用记录 R）**仍参与统计**——其计算成本应被纳入"未结算"统计，避免对账期间作废导致成本数据"消失"；完成对账时 R 被释放回池（作废标记置正常、明细状态置空），自然转入"未结算"统计。

结算状态仅以「是否有结算策略」「是否为清账」及「是否完成对账」三方归类：

| 指标                   | 判定条件（对账明细底表，已排除 R'）                             | 说明                                                                                                                         |
| ---------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **已结算金额（计算）** | `明细状态=已完成` 且 `结算策略` 非空 且 ≠ 清账 | 已选定结算策略（支付类）且完成对账的记录                                                                                     |
| **未结算金额（计算）** | `明细状态` ≠ 已完成 | 不属于"已结算"且不属于"不结算"的记录，包含：① 账单未上传（`对账单ID`为空，明细状态=空）；② 账单已上传但结算策略未选（明细状态非空且≠已完成）；③ 已选定策略但尚未完成对账（明细状态非空且≠已完成）；④ 对账中阶段被标记作废但未完成对账的记录（`作废标记=作废`、`明细状态≠已完成`，含成本未释放的 R） |
| **不结算金额（计算）** | `明细状态=已完成` 且 `结算策略` = 清账 | 标记清账且已完成对账的记录，不结算唯一来源                                                                                   |

### 2.3 币种与金额口径

- 全表金额均不做跨币种折算或累加；各记录币种取`币种`字段。
- 4 个「金额（计算）」列均取对账明细底表 `最新计算金额`。
- **空值处理规则**：统计时，`最新计算金额` 字段的空值视为 0 参与计算。

## 三、统计维度

| 维度     | 字段                                                                                 | 说明                                                                                                                  |
| -------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| 供应商   | 供应商编码、供应商名称                                                               | 取值来源：对账明细底表 `供应商编码`、`供应商名称` 字段                                                                |
| 账单类型 | 账单类型                                                                             | 取值来源：对账明细底表 `账单类型`；可选值：国内转运 / 内地空运 / 香港空运 / 空运卡转 / 国外清关 / 国外转运 / 尾程派送 |
| 业务期间 | 单据时间整月（YYYY-MM）<br>取值：对账明细底表`单据时间`字段 | 格式：YYYY-MM                                                                                                         |
| 币种     | 币种                                                                                 | 取值来源：对账明细底表 `币种` 字段                                                                                    |

## 四、页面布局

### 4.1 筛选条件

| 字段名称 | 类型             | 必填性 | 说明                                                                                    |
| :------- | :--------------- | :----- | :-------------------------------------------------------------------------------------- |
| 业务期间 | 月份选择         | 否     | 按单据时间整月筛选；**默认最近一个完整月**（例：7月打开默认=2026-06），贴合月度扫描场景 |
| 供应商   | 多选下拉（复选） | 否     | 按供应商筛选，支持多选，多选时取并集                                                    |
| 账单类型 | 多选下拉（复选） | 否     | 按账单类型筛选，支持多选，多选时取并集                                                  |
| 币种     | 多选下拉（复选） | 否     | 按币种筛选，支持多选，多选时取并集                                                      |

### 4.2 操作按钮

| 按钮名称 | 功能说明             | 前置条件 |
| :------- | :------------------- | :------- |
| 查询     | 根据筛选条件查询报表 | 无       |
| 重置     | 清空所有筛选条件     | 无       |
| 导出     | 导出当前报表数据     | 无       |

### 4.3 报表展示

按 **4 维度 GROUP BY 聚合**：供应商编码 + 账单类型 + 业务期间 + 币种，缺一不可；供应商名称作为展示列随编码带出。

每行并列展示 4 个金额列：总金额（计算）、已结算金额（计算）、未结算金额（计算）、不结算金额（计算）。

默认按「未结算金额（计算）」倒序排列，未结算金额（计算）相同再按总金额（计算）倒序，优先展示需要跟进的大头。

| 字段名称           | 说明                                                                                     |
| :----------------- | :--------------------------------------------------------------------------------------- |
| 供应商编码         | 供应商编码                                                                               |
| 供应商名称         | 供应商名称                                                                               |
| 账单类型           | 国内转运 / 内地空运 / 香港空运 / 空运卡转 / 国外清关 / 国外转运 / 尾程派送               |
| 业务期间           | 单据时间整月，格式 YYYY-MM                                                               |
| 币种               | 取值来源：对账明细底表`币种`字段                                                         |
| 总金额（计算）     | 该维度下所有记录 `最新计算金额` 合计（已排除 R'）                                         |
| 已结算金额（计算） | `明细状态=已完成` 且 `结算策略` 非空且 ≠ 清账 的记录（已排除 R'），取 `最新计算金额` 合计 |
| 未结算金额（计算） | `明细状态` ≠ 已完成 的记录（已排除 R'，含对账中作废未释放的 R），取 `最新计算金额` 合计 |
| 不结算金额（计算） | `明细状态=已完成` 且 `结算策略` = 清账 的记录（已排除 R'），取 `最新计算金额` 合计 |
