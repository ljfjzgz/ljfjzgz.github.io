# 对账单列表

## 零、导入对账单

在列表页通过「导入对账单」按钮（弹窗）提交供应商账单文件，生成一条对账单草稿数据，随后在下方列表继续后续处理。

### 页面字段

| 字段       | 说明                                       | 必填 |
| :--------- | :----------------------------------------- | :--- |
| 供应商     | 下拉选择已维护供应商（如 SHAOKE / DHL_ECOMMERCE / TAIJIA） | 是   |
| 账单文件   | 上传供应商原始账单文件                     | 是   |

> 仅两个输入项，无其余表单字段；「确认」即弹窗中的「保存」按钮。

### 操作步骤

1. 点击列表页「导入对账单」按钮，打开导入弹窗；
2. 选择**供应商**；
3. 点击「选择文件」上传**账单文件**；
4. 点击「确认」，系统解析账单文件、在下方列表**生成一条对账单数据**（初始为**草稿**状态）；**导入仅落账单明细数据，不写入对账明细底表**——底表的匹配与占用在详情页「开始对账」时才执行（见《4.对账明细底表》）。

## 三、状态说明

列表「状态」取值（来自账单处理流程）：

| 状态 | 含义 | 流转 |
| :--- | :--- | :--- |
| 草稿 | 已导入，待编辑确认后推进 | 编辑确认 → 待对账 |
| 待对账 | 已确认，待「开始对账」 | 「开始对账」→ 对账中 |
| 对账中 | 已「开始对账」：底表记录占用 + 差异判定完成，可逐条处理 / 重新对比，尚未完成对账 | 执行「完成对账」→ 已完成；「取消对账」→ 待对账 |
| 已完成 | 执行「完成对账」后终态：对账明细底表回写付款金额/会计期间、已生成账单管理数据 | 不可逆（调整走业务冲销，见《3.对账单生成账单管理记录逻辑》） |

> 流转说明：
> - **草稿 → 待对账**：用户在详情页编辑确认后（点击「确认」或「保存并推进至待对账」）手动推进；导入仅落账单明细，不写底表。
> - **待对账 → 对账中**：在明细页点「开始对账」，系统按 `系统ID+费用项+币种` 匹配成本、占用底表记录、截取快照计算金额并跑差异判定。
> - **对账中（可停留）**：支持逐条「重新对比」（归位合并检查 + 重截快照 + 重跑差异），仅对**结算策略为空且未作废**的明细重跑，已确认结算策略的明细跳过；状态保持对账中不变。
> - **对账中 → 已完成**：执行「完成对账」，校验通过后回写底表、生成账单管理数据；为终态不可逆。
> - **对账中 → 待对账（取消对账）**：执行「取消对账」，释放底表记录占用、清除快照计算金额，回到待对账；采用软取消——保留逐条明细与已确认结算策略，可直接重开对账。

> 注：账单生成状态（是否已生成账单管理数据）由独立的「是否生成账单」字段记录，不归入上述工作流状态；其取值与 `账单管理ID` 回写见《3.对账单生成账单管理记录逻辑》。
