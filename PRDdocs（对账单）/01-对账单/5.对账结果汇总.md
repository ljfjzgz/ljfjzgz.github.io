# 对账结果汇总

> **入口**：在对账单详情页点击「下载对账结果汇总」按钮下载Excel文件，开始对账后即可下载，对账中及已完成状态均支持，每次下载时实时从底表重新汇总。

## 一、汇总维度

| 类型     | 字段名称              | 说明                                                      |
| :------- | :-------------------- | :-------------------------------------------------------- |
| **维度** | 结算策略              | 按结算策略分组统计 |
| **维度** | 差异类型              | 按差异类型分组统计                                        |
| **维度** | 费用项                | 对账费用项维度                                            |
| **显示** | 币种                  | 显示该对账单的币种                                        |
| **度量** | 账单金额              | 供应商账单金额合计                                        |
| **度量** | 快照计算金额          | 对账时固化的成本快照合计                                  |
| **度量** | 计算差异               | 账单金额 - 快照计算金额                                   |
| **度量** | 账单金额占比          | 该差异类型账单金额 / 总账单金额                           |

## 三、汇总规则

1. **分组汇总**：按结算策略 + 差异类型 + 费用项分组，展示明细数据
2. **小计行**：每个差异类型展示 1 行小计，汇总该差异类型下所有费用项（跨结算策略相同差异类型分别小计）
3. **总计行**：展示 1 行总计，汇总该对账单所有结算策略、所有差异类型的合计
4. **账单金额占比计算**：单条 / 小计 / 总计的账单金额 ÷ 总账单金额
5. **数据来源**：对账明细底表，按`对账单ID`筛选，仅汇总归属该对账单的数据，不汇总其他对账单的数据
6. **汇总时机**：每次下载时实时从底表按`对账单ID`汇总，反映当前对账进度；对账中状态下可随时下载预览，完成对账为终态不可逆，完成后再次下载结果与完成时一致
7. **空值置换**：快照计算金额为空时置换为0参与统计和合计
