# 对账结果汇总

> **入口**：在对账单详情页（见《2.对账单详情》2.2节）点击「下载对账结果汇总」按钮下载，开始对账后即可下载。

## 一、汇总维度

| 类型     | 字段名称              | 说明                             |
| :------- | :-------------------- | :------------------------------- |
| **维度** | 差异类型              | 按差异类型分组统计               |
| **维度** | 费用项名称            | 对账费用项维度                   |
| **显示** | 币种                  | 显示该对账单的币种               |
| **度量** | 账单金额              | 供应商账单金额合计（原币）       |
| **度量** | 快照计算金额          | 对账时固化的成本快照合计（原币） |
| **度量** | 金额差异（账单-快照） | 账单金额 - 快照计算金额（原币）  |
| **度量** | 账单金额占比          | 该差异类型账单金额 / 总账单金额  |

## 三、汇总规则

1. **分组汇总**：按差异类型 + 费用项名称分组，展示明细数据
2. **小计行**：每个差异类型展示 1 行小计，汇总该类型下所有费用项
3. **总计行**：展示 1 行总计，汇总该对账单所有差异类型的合计
4. **账单金额占比计算**：单条 / 小计 / 总计的账单金额 ÷ 总账单金额
5. **数据来源**：对账明细底表（《4.对账明细底表》），按`对账单ID`筛选，仅汇总归属该对账单的数据，不汇总其他对账单的数据
6. **汇总时机**：完成对账回写底表后从底表汇总，完成对账为终态，汇总结果不随后续操作刷新
7. **空值置换**：快照计算金额为空时置换为0参与统计和合计
