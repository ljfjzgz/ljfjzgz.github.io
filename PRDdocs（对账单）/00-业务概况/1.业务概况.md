# 业务概况

> 项目名称：系统对账与成本计提优化
> 文档版本：V1.0
>
> **术语约定**
>
> - **对账管理模块**：本次新建的独立对账功能模块（含对账明细底表），账单导入、比对、确认均在本模块内完成。对账明细页为按对账单ID查询底表的视图，无独立物理表。
> - **账单管理模块（旧系统）**：既有系统表，仅接收对账管理模块确认后数据的**单向同步**，不参与对账过程。
> - **供应商账单**：供应商发来的账单文件，导入对账管理模块处理。
> - **对账阶段状态**：在对账单原有状态基础上融入——**草稿→待对账→对账中（新增，点击「开始对账」后进入）→已完成（即对账完成，终态不可逆）**。
> - **开始对账**：用户在待对账账单上手工触发，系统按`供应商编码+系统ID+费用项+币种`维度校验底表（同主键下存在未完成对账占用则拦截），通过后占用对账明细底表（写入对账单ID、截取快照计算金额、明细状态→系统对比中）。
> - **取消对账**：将对账中的账单退回待对账，解锁其占用的底表记录（清空账单信息、快照与结算策略、明细状态置空）；追加记录直接删除、最早记录纯解绑保留。
> - **最新计算金额 / 快照计算金额**：最新计算金额由单据侧持续同步（不受明细状态限制）；快照计算金额在开始对账时截取固化，作为差异判定基准。
> - **明细状态**：标识记录在对账处理流程中的状态，6种枚举（空/系统对比中/待处理/已处理/已变更待复核/已完成）；明细状态=空表示未占用可被分配，=已完成表示完成对账终态。
> - **作废标记与释放**：作废明细完成对账时释放原占用记录回池（可被新账单占用）+新增作废追加记录（仅用于底表查询追溯，不参与统计/清账/计提）；所有统计/清账/计提模块统一按`作废标记=正常`过滤。

---

## 1.1 业务背景

本公司跨境物流业务覆盖从国内揽收到目的国派送的全程运输链路，按成本段划分为四段，每段对应若干账单类型（详见下表）：

| 成本段 | 类型（账单类型）               | 单据 |
| :----- | :----------------------------- | :--- |
| A 段   | 国内转运                       | 运单 |
| B 段   | 内地空运 / 香港空运 / 空运卡转 | 运单 |
| C 段   | 国外清关 / 国外转运            | 运单 |
| D 段   | 尾程派送                       | 订单 |

- **A/B/C 段**：以「运单」为单据维度，**D 段**：以「订单」为单据维度
- 各成本段包含若干账单类型，同成本段内标准费用项集合一致

## 1.2 当前痛点

### 1.2.1 计算成本不稳定，当月成本无法准确统计

| 痛点             | 说明                                                               |
| :--------------- | :----------------------------------------------------------------- |
| 计算成本频繁变动 | 系统计算成本因费率规则调整等原因持续变动，缺乏稳定基准             |
| 实际成本陆续确认 | 供应商按各自账期陆续出账，实际成本分批到达                         |
| 时间节奏脱节     | 计算成本一直在变，实际成本间歇到账，当月实际成本发生额难以准确统计 |

### 1.2.2 对账粒度粗，依赖大量人工

| 痛点         | 说明                                                                   |
| :----------- | :--------------------------------------------------------------------- |
| 单据级对账   | 当前对账将同一单据下多个费用项合并汇总后对比，无法定位到具体费用项差异 |
| 差异难以定责 | 单据级合并对比，出了差异无法判断是哪个费用项导致，难以追因             |
| 大量人工判断 | 差异识别主要依赖财务人工操作                                           |
| 数据人工搬运 | 对账结果需人工搬运到金蝶财务系统入账                                   |

### 1.2.3 费用项级结算策略需完善

当前已有初步的费用项级处理能力，但不够完善，需在此次项目中进一步规范和增强。

## 1.3 项目目标

### 1.3.1 对账粒度

- **从**：单据级（一单多费用项合并汇总对比）
- **到**：单据 + 费用项级（一行一费用项，逐行对比）

### 1.3.2 差异自动化判断

系统按预设的差异判断逻辑，自动对每条（单据号+费用项）明细标记差异类型，共 **11 种**，分五类（其中10种为系统自动判定，1种为清账流程自动写入）：

- **正常类**：无差异
- **金额对比类**：重量偏差（wb＞cp / wb＜cp）、金额差异（非计费重因素）
- **对账状态类**：历史已对账、单据无计费、费用项无计费、供应商不一致
- **单据异常类**：成本系统无单据、对账币种不一致
- **特殊流程类**：清账（清账单流程自动写入，非系统判定，详见清账单流程）

> **说明**：
>
> - 差异判定的成本口径统一为**快照计算金额**（开始对账时截取）。
> - 同一账单文件内`系统ID+费用项+币种`重复数据在**导入环节直接拦截**，不进入对账（同一账单的供应商为单头级字段，无需参与明细重复校验）。

### 1.3.3 费用项级结算策略

完善费用项维度的结算策略，采用 **「支付基准 × 是否争议」7 种组合枚举**（单字段存储），涵盖正常付款类与不结算类：

- **正常付款类（4 种）**：按账单金额支付+不争议、按账单金额支付+争议、按系统金额支付+不争议、按系统金额支付+争议
- **不结算类（3 种）**：不支付+不争议、不支付+争议、清账（仅系统自动写入，对账页不可手动选）

> **结算策略确定方式**：结算策略由财务在对账时**人工选择确定**，系统不自动带出。

### 1.3.4 费用项映射统一

对账统一以内部标准费用项为基准，需解决以下关键设计问题：

> **一对多映射矛盾**：以清关运单的「清关费」为例——计算成本侧用一个费用项 CODE 归集，而实际成本侧按不同计费因子（如按包裹数、按运单数、按核重）拆分为多个独立 CODE，此类情况在清关业务中真实存在。如何建立准确的映射关系，是项目必须明确的设计事项之一。

### 1.3.5 自动化报表输出

基于对账数据自动化产出：

- **成本计提汇总数据**：作为金蝶入账依据
- **对账问题汇总报表**：按差异类型、供应商、费用项等维度汇总
- **应付账单统计表**：按供应商、结算状态等维度统计应付账款，支持财务管控与资金计划

## 1.4 核心设计原则

### 1.4.1 不做调账，保留原始数据

计算成本与实际成本之间的差异**不强制抹平**。系统自动生成差异明细记录（仅作统计和分析用途），原始数据各自保留不修改。

### 1.4.2 对账层数据独立与明细状态机制

- **计算成本**：按原有逻辑继续正常变动，不受对账影响
- **双金额机制**：`最新计算金额`持续同步、`快照计算金额`截取固化，二者分别支撑报表与对账口径，确保对账口径稳定
- **明细状态机制**：手工「开始对账」时，按`供应商编码+系统ID+费用项+币种`维度校验底表（同主键下存在未完成对账占用则拦截），通过后占用底表记录（写入对账单ID、账单金额，截取快照计算金额，明细状态→系统对比中）
- **解锁规则**：「取消对账」时自动解锁——追加记录直接删除、最早记录纯解绑保留（清空对账单信息、快照计算金额与结算策略，明细状态置空）；**不再执行归位合并**（开始对账校验机制确保同主键下不会出现"前一份未完成后一份已开始"的合并场景）
- **重新对比**：对账中阶段可手动触发「重新对比无结算策略明细」——仅对**结算策略为空（会计尚未确认）且未作废**的明细重新截取快照计算金额、重跑差异判定，已确认结算策略的明细跳过
- **差异处理原则**：对账差异不调差，仅记录原始对账数据，需要时再基于源数据统计
- **效果**：对账用快照口径，结果稳定可追溯；报表/计提用最新口径，反映真实成本；两条线各自独立运行

### 1.4.3 对账周期按供应商账期

不以固定自然月为周期，而是跟随各供应商的实际账期开展对账。

### 1.4.4 历史对账提醒不阻断

历史已对账的费用项在本期账单中再次出现时，系统做出提示标记，但**不直接排除该费用项**。是否对本期该费用项付款、按什么策略结算，由财务人员最终决定。

### 1.4.5 费用项展示规则

对账明细以供应商账单费用项为基准展开，展开粒度为`供应商编码+系统ID+费用项+币种`：账单中不存在的费用项不展示，账单金额为 0 的费用项仍需展示。

## 1.5 核心业务流程（概要）

```
供应商发送账单 → 财务导入对账管理模块（生成对账单，导入不写底表，状态 → 草稿）
    → 用户编辑确认后手动推进至 待对账
    → 手工「开始对账」（校验底表占用+占用底表 + 截取快照计算金额，明细状态→系统对比中，状态 → 对账中）
    → 按费用项逐行对比 → 自动标记差异类型 → 财务确认/调整结算策略
    → 「完成对账」（校验通过后状态 → 已完成，终态不可逆；有效明细明细状态→已完成，作废明细释放原占用记录回池+新增作废追加记录）
    → 生成差异汇总和计提数据 → 输出报表
```

**终态与冲销**：对账完成即终态不可回退，如需调整须走冲销（追加负数账单再对账），保证已入账数据不被污染。
