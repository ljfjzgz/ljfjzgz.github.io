# 对账单生成账单管理记录逻辑

## 1. 概述与核心关系

- 数据流向唯一：对账管理模块（对账单）完成对账后，系统**自动生成**对应的账单管理记录并写入账单管理模块，而非字段级同步。
- 对账单与账单管理记录为 **1:1** 关系：一张对账单整合其全部对账明细后，系统据此在账单管理列表生成一条账单管理记录（含各费用项明细）；该记录生成后，系统将其 `账单管理ID` **回写**到对账单，作为两端关联键。

ID 命名约定（全套文档统一）：
- `底表明细ID`：对账明细底表记录唯一主键，系统自动生成；
- `对账单ID`：对账单唯一标识，开始对账时写入底表记录，表示被哪张对账单占用；
- `账单管理ID`：对账完成后生成的账单管理侧记录ID，回写到对账单；本文档关联键均指 `账单管理ID`。

## 2. 生成时机

- 触发粒度：按对账单（非按底表行、非按明细项）。
- 触发条件：对账单在**对账中**执行「完成对账」——校验通过后，对账单进入**已完成（对账完成）**。
- 完成动作：系统将完成对账信息回写至对账明细底表（记录状态→已完成），随后立即按生成规则自动生成账单管理记录（1:1）。
- 生成前校验：该对账单 `账单管理ID` 尚未回写（即尚未生成过），避免重复生成，保证 1:1 唯一性。

> **对账完成不可逆**：对账完成为终态，不可回退到对账中/待对账；如需调整已完成结果，走业务冲销（追加负数账单重新对账），不提供状态回退，避免已生成的账单管理记录与已入账数据被污染。

## 3. 生成规则

- 账单管理记录以导入对账单的字段结构为基础，各字段取值与该文档保持一致。
- 唯一差异：各费用项金额以对账确认后的**付款金额**替换导入时的对应金额（取值口径在生成时固化，后续重新生成不再重算）。

## 4. 删除与重新生成

- 账单管理侧删除：用户在账单管理模块删除某条账单管理记录。
- 对账侧联动：对账管理模块通过回写的 `账单管理ID` 检测到对应记录已删除，将本对账单「是否生成账单」置为**否**、清空 `账单管理ID`；对账单工作流状态保持不变，生成状态由独立标识字段记录。
- 重新生成入口：对「是否生成账单 = 否」的对账单，在对账单列表/详情页提供"重新生成"按钮：
  - 按生成规则再次自动生成对应的账单管理记录（恢复 1:1）；取值口径不变（费用项仍取对账完成时的付款金额），**不重新对账**。
  - 生成成功后「是否生成账单」置为**是**、`账单管理ID` 由账单管理侧回写。
- 设计要点：对账单始终是源头；删除发生在账单管理侧时不影响对账数据本身，仅开放"重新生成"能力。

## 5. 数据一致性

- 对账管理模块是对账数据**唯一源头**；账单管理记录由系统自动生成，是账单管理侧的独立副本，不参与对账过程。
- 1:1 关系通过对账单上的 `账单管理ID`（由账单管理侧回写）维护，生成/删除/重新生成均以该键做幂等处理，不重复写入。
