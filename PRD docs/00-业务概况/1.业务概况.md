# 业务全局赔付数据一体化管理 - 业务概况（小包业务）

> **文档说明**：基于2026年5月13日会议纪要整理，明确小包业务背景、目标及整体架构
> **适用范围**：仅小包业务，外销业务请参阅 PRD docs2 目录

---

## 一、业务背景

### 1.1 现状痛点

| 痛点               | 现状描述                                                 | 影响               |
| ------------------ | -------------------------------------------------------- | ------------------ |
| **数据管理混乱**   | 赔付数据依赖线下表格，每人填写格式不一，年度大表难以管理 | 数据难以统计、分析 |
| **缺乏系统化流程** | 客户赔付与供应商索赔脱节，无联动机制                     | 责任不清、索赔滞后 |
| **客户体验差**     | 客户无法查询订单赔付明细，账单记录混乱                   | 客户投诉、销售被动 |
| **财务结算复杂**   | 平台扣罚与申诉跨月处理，财务按实结算困难                 | 账目不清、对账困难 |

## 二、业务目标

建立**小包业务赔付数据一体化管理**，实现：

| 目标维度       | 具体实现                                             |
| -------------- | ---------------------------------------------------- |
| **数据标准化** | 统一赔付导入模板，废弃零散表格                       |
| **流程独立化** | 客户赔付与供应商索赔独立运行，索赔由运营人员手动发起 |
| **底表统一化** | 赔付与索赔数据在订单维度统一汇总，支持净赔付分析     |
| **数据可视化** | 客户后台可查询赔付记录；内部支持运营分析及责任判定   |

## 三、业务分类体系

| 一级业务     | 二级业务/场景     | 数据维度 | 处理特点            | 系统对接        |
| ------------ | ----------------- | -------- | ------------------- | --------------- |
| **小包业务** | 客户赔付-主流程   | 订单维度 | 标准赔付流程        | 主流程          |
|              | 客户赔付-平台扣罚 | 订单维度 | 涉及平台扣罚及申诉  | 主流程+申诉流程 |
|              | 供应商索赔-ABC段  | 运单维度 | 成本段ABC按运单索赔 | 独立流程        |
|              | 供应商索赔-D段    | 订单维度 | 成本段D按订单索赔   | 独立流程        |

---

## 四、单据关联关系

### 4.1 核心单据与业务流转

| 单据类型                | 关联单据 | 业务说明             |
| ----------------------- | -------- | -------------------- |
| **客户赔付单-主流程**   | 订单     | 标准赔付，完结后归档 |
| **客户赔付单-平台扣罚** | 订单     | 支持申诉，独立流程   |
| **供应商索赔单-ABC段**  | 运单     | 按计费重分摊至订单   |
| **供应商索赔单-D段**    | 订单     | 直接关联订单         |
