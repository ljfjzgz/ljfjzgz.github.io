# 赔付导入说明

---

## 一、操作类型概览

| 操作类型         | 模板字段                                               | 核心匹配键                          | 业务场景                      |
| ---------------- | ------------------------------------------------------ | ----------------------------------- | ----------------------------- |
| **导入新增赔付** | 处理号、赔付原因、赔付币种、赔付金额、赔偿标准、备注   | 处理号+赔付原因（查未红冲记录，存在则阻断，已红冲可重新导入） | 导入新增赔付数据              |
| **批量回填申诉** | 处理号、赔付原因、申诉结果、最终赔付金额原币、申诉说明 | 处理号 + 赔付原因（且红冲单号为空） | 批量回填KPI扣罚类型的申诉结果 |

## 二、导入新增赔付

> 赔付原因需在赔付原因配置表中存在，详见 [赔付原因（客户）](../01-赔付类型配置/赔付原因（客户）.md)

### 2.1 模板字段

| 模板列 | 字段名称 | 必填 | 校验规则                                       | 导入后展示                        |
| ------ | -------- | ---- | ---------------------------------------------- | --------------------------------- |
| A      | 处理号   | 是   | 非空且需在OMS订单表中存在                      | -                                 |
| B      | 赔付原因 | 是   | 非空且需在赔付原因基础表存在，自动带出赔付类型 | -                                 |
| C      | 赔付币种 | 是   | 非空且为标准币种代码（USD、CNY、EUR等）        | 与金额合并展示为「USD 50.00」格式 |
| D      | 赔付金额 | 是   | 非空，大于0，最多2位小数                       | 与币种合并展示为「USD 50.00」格式 |
| E      | 赔偿标准 | 否   | 最多100字符，超长截断                          | -                                 |
| F      | 备注     | 否   | 最多200字符，超长截断                          | -                                 |

### 2.2 组合唯一性校验

> 此查询与 [三、3.2 批量回填申诉](#32-匹配与校验逻辑) 匹配逻辑相同，但业务结果相反：此处存在则阻断，彼处存在则继续校验。

```
查询条件：处理号 = 导入值 AND 赔付原因 = 导入值 AND 红冲单号 IS NULL
```

| 场景             | 结果        | 说明                       |
| ---------------- | ----------- | -------------------------- |
| 记录存在         | ❌ 阻断导入 | 该订单此原因已有未完结赔付 |
| 记录不存在       | ✅ 允许导入 | -                          |
| 记录存在但已红冲 | ✅ 允许导入 | 红冲单号有值视为已冲销     |

> **错误提示**：处理号【{处理号}】已存在赔付原因【{赔付原因}】的未完结赔付记录，请勿重复导入。如需重新赔付，请先红冲原赔付单。

### 2.3 导入后处理

- 校验通过的数据立即创建赔付单，状态为【待审核】
- 导入完成后显示结果汇总（成功X条/失败Y条），支持下载失败提示文档（格式见下方）

| ------- | -------- | -------- | -------- | -------------- | ---- | ---------------------------------------------------------- |
| WNB001  | 尾程丢失 | USD      | 50.00    | 按申报价值赔付 |      | 处理号【WNB001】已存在赔付原因【尾程丢失】的未完结赔付记录 |
| WNB002  |          | USD      | 30.00    |                |      | 赔付原因不能为空                                           |
| INVALID | 尾程破损 | CNY      | 100.00   |                |      | 处理号【INVALID】在OMS订单表中不存在                       |
| WNB003  | 无效原因 | EUR      | 25.50    |                |      | 赔付原因【无效原因】不存在，请核对后重新填写               |
| WNB004  | 尾程丢失 | KFC      | 40.00    |                |      | 赔付币种【KFC】无效，请使用标准币种代码（如USD、CNY、EUR） |

## 三、批量回填申诉

### 3.1 模板字段

| 模板列 | 字段名称             | 必填 | 校验规则                                                         | 导入后展示                                   |
| ------ | -------------------- | ---- | ---------------------------------------------------------------- | -------------------------------------------- |
| A      | **处理号**           | 是   | 非空，需在OMS订单表中存在                                         | -                                            |
| B      | **赔付原因**         | 是   | 非空，需在赔付原因基础表存在，且与处理号组成复合匹配键            | -                                            |
| C      | 申诉结果             | 是   | 枚举值：成功、失败                                                | -                                            |
| D      | **最终赔付金额原币** | 条件 | 仅申诉结果=成功时必填，只填数字；币种自动取原赔付金额币种；金额应 ≤ 原赔付金额 | 申诉成功时展示，与币种合并为「USD 50.00」格式 |
| E      | 申诉说明             | 否   | 最多200字符，超长截断                                             | 申诉失败时展示                               |

### 3.2 匹配与校验逻辑

#### STEP 1：唯一匹配

```
SELECT * FROM 小包客户赔付表
WHERE 处理号 = 导入值
  AND 赔付原因 = 导入值
  AND 红冲单号 IS NULL
```

| 匹配结果  | 处理                                                       |
| --------- | ---------------------------------------------------------- |
| **0 条**  | ❌ 失败："处理号【X】+赔付原因【Y】未找到未红冲的赔付记录" |
| **1 条**  | ✅ 进入 STEP 2 校验                                        |
| **≥2 条** | ❌ 系统唯一性异常，标记失败（理论不应发生）                |

#### STEP 2：前置条件校验

| 校验项                      | 失败原因                                               |
| --------------------------- | ------------------------------------------------------ |
| **赔付类型 = KPI扣罚**      | 处理号【X】赔付类型为【Y】，需KPI扣罚类型才能回填申诉  |
| **赔付状态 = 已完结**       | 处理号【X】当前赔付状态为【Y】，需已完结才能回填申诉   |
| **申诉状态 = 申诉中**       | 处理号【X】当前申诉状态为【Y】，需申诉中才能回填       |
| **红冲单号 IS NULL**        | 处理号【X】已有红冲记录（红冲单号【Z】），不可重复申诉 |
| **最终赔付金额 ≤ 赔付金额（原赔付单金额）** | 处理号【X】最终赔付金额【A】大于原赔付金额【B】，请确认  |

### 3.3 导入后处理

- 校验通过的数据，执行以下操作：
  1. 更新赔付单的申诉状态（成功/失败）
  2. 更新最终赔付金额原币到赔付单
  3. 计算申诉金额原币 = 赔付金额原币 - 最终赔付金额原币；取审核通过时间汇率计算申诉汇率、申诉金额CNY；自动生成申诉红冲单（金额 = -(申诉金额差额)），**同时立即回填红冲单号到原赔付单**，并推送财务
- 导入完成后显示结果汇总（成功X条/失败Y条），支持下载失败提示文档（格式同 [2.4](#24-失败提示文档格式)，列结构随模板字段而变化）

| ------ | -------- | -------- | ---------------- | -------- | ------------------------------------------------- |
| WNB001 | KPI扣罚  | 成功     | 20.00            |          | 已通过校验                                        |
| WNB002 | KPI扣罚  | 成功     | 50.00            |          | 当前赔付状态为【待审核】，需已完结才能回填申诉    |

| WNB004 | 尾程丢失 | 成功     | 30.00            |          | 赔付类型为【异常赔付】，需KPI扣罚类型才能回填申诉 |
