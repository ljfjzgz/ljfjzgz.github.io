# 04 看数据

本章讲两个只读页面：**订单赔付索赔底表**（按订单看全量赔付索赔汇总）与**赔付索赔匹配统计表**（按匹配状态看统计分布）。这两页都没有录入操作，回答的是"这个订单赔了多少、索了多少、匹配情况如何"。

---

## 5.1 订单赔付索赔底表

### 5.1.1 查询与导出

**什么时候做**：需要按订单查看赔付/索赔净额、核对某笔分摊结果、或检查匹配情况。

**在哪做**：订单赔付索赔底表页。

**怎么做**：列表支持按以下字段筛选（字段含义见附录 B.4）：处理号（支持批量查询）、客户代码、客单号、跟踪号、目的国、渠道代码、产品代码、提单号、箱号、扣费时间、出库时间、匹配状态。

**做完会怎样**：点【导出】下载当前筛选结果（包含列表页全部字段）。

### 5.1.2 查看单个订单的赔付索赔明细

**怎么做**：点击列表中**处理号**链接，跳转详情页，展示该处理号下的两类明细：

- 客户赔付明细（来源小包客户赔付表）；
- 供应商索赔明细（来源干线索赔与尾程索赔，干线为分摊后数据）。

### 5.1.3 数据怎么来的

底表不需要维护，所有数据由上游自动写入（以处理号为唯一维度汇总）：

| 来源 | 写入时机 |
| --- | --- |
| 客户赔付 | 审核通过时、KPI 扣罚申诉金额计算完成时实时写入 |
| 干线索赔 | 回填确认金额触发分摊，分摊完成后写入 |
| 尾程索赔 | 回填确认金额后实时写入 |

汇总规则：

- 各金额字段均为该处理号下所有明细的汇总，**含红冲数据**（红冲为负值），因此某笔红冲后金额可能变小甚至为负；
- 各"次数"字段统计明细笔数，含所有状态与红冲数据；
- 索赔确认差异 CNY = 索赔金额 CNY − 确认金额 CNY；赔付索赔差异 CNY = 赔付金额 CNY − 确认金额 CNY（客户视角净损失/收益）；
- 匹配状态按赔付次数与索赔次数判定，判定逻辑见 00-认识系统 §1.3；
- **底表一行 = 一个处理号（订单维度）**，不是一条赔付或索赔明细一行；同一处理号下的多条明细都汇总在这一行里，明细要点进详情页看（见 5.1.2）；
- **赔付金额 CNY 已经含了申诉红冲的负数**（申诉成功会把净赔付冲减到最终赔付金额），所以不要再拿「赔付金额 CNY − 申诉金额 CNY」算一次；申诉金额 CNY 是另一列，记的是冲回了多少。

**示例**（处理号 OD001 下 3 条明细，汇率均为 7.1000）：

| # | 明细 | 原币金额 | CNY | 计入底表哪一列 |
| --- | --- | --- | --- | --- |
| 1 | 赔付单 PYC001 | USD 100.00 | 710.00 | 赔付金额 CNY |
| 2 | 该单申诉成功（最终赔付 30），生成申诉红冲单 | -USD 70.00 | -497.00 | 赔付金额 CNY |
| 3 | 索赔单 CLA001，回填确认 USD 80.00 | USD 90.00 / 80.00 | 639.00 / 568.00 | 索赔金额 CNY / 确认金额 CNY |

汇总成底表的一行：

| 底表字段 | 值 | 算法 |
| --- | --- | --- |
| 赔付次数 | 2 | 明细 1 + 明细 2（红冲也计一次） |
| 赔付金额 CNY | 213.00 | 710.00 - 497.00 |
| 申诉金额 CNY | 497.00 | 冲回了多少，单独记一列 |
| 索赔次数 | 1 | 明细 3 |
| 索赔金额 CNY | 639.00 | USD 90.00 × 7.1000 |
| 确认金额 CNY | 568.00 | USD 80.00 × 7.1000 |
| 索赔确认差异 CNY | 71.00 | 639.00 - 568.00 |
| 赔付索赔差异 CNY | -355.00 | 213.00 - 568.00 |
| 匹配状态 | 有赔付有索赔 | 赔付次数 > 0 且 索赔次数 > 0 |

213.00 已经是扣掉申诉后的净额，不用再减 497.00；再减一次得 -284.00，是错的。

## 5.2 赔付索赔匹配统计表

### 5.2.1 按时间范围查询

**什么时候做**：需要回顾一段时间内赔付索赔的整体分布。

**怎么做**：设置筛选：

| 筛选字段 | 说明 |
| --- | --- |
| 时间类型 | 默认「出库时间」，可切换为「扣费时间」 |
| 时间范围 | **单次最长三个月** |

**做完会怎样**：报表按底表的【匹配状态】分组展示，共三行（有赔付无索赔 / 有索赔无赔付 / 有赔付有索赔），每行包含：

| 字段 | 含义 |
| --- | --- |
| 订单数量 | 该匹配状态下的订单笔数 |
| 赔付金额 CNY | 客户赔付总金额 |
| 申诉金额 CNY | 申诉成功总金额 |
| 索赔金额 CNY | 向供应商索赔总金额 |
| 确认金额 CNY | 供应商确认赔付总金额 |
| 赔付索赔差异 CNY | 赔付金额 CNY − 确认金额 CNY |

**注意**：

- 统计口径完全取自底表的【匹配状态】字段——底表数据（含红冲取负、分摊结果）变化会直接反映到统计结果；时间范围只限定统计区间，不改变任何金额口径。
- **三行互斥且覆盖全部底表数据**：每个处理号只落进其中一行，三行订单数量相加就是区间内的底表订单总数，不会漏也不会重。
