# 02 导入与建档

> 本章讲一张对账单怎么进系统、并推进到可以开始对账：**导入 → 核对补全 → 删错单**。到【待对账】为止，本章就结束了；开始对账之后的操作见 03 章，完成对账之后的补生成见 04 章 4.4。金额口径与状态含义见 01 章。

---

## 2.1 把供应商账单导进来

**什么时候做**：收到供应商账单，按各供应商账期推进。

**在哪做**：列表页「导入对账单」按钮，弹窗操作。

**怎么做**：分两步——先把供应商账单整理成标准账单，再导入。

1. **整理**：在导入弹窗点「下载导入模板」，拿到标准格式模板；线下把供应商账单的内容按模板逐行填好。系统目前只认这个格式，供应商发来的原始文件不能直接导入。

   模板里有多个 sheet：**基础信息**一个，之后**每个账单类型各一个**。一张对账单只能是同一个账单类型，所以导入时系统先读基础信息，再按顺序往后找，**读到第一个有内容的账单类型 sheet 就停**——后面的 sheet 不再读。
2. **导入**：弹窗里选供应商、上传整理好的标准账单文件，点「确认」。

弹窗只有两个输入项：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 供应商 | 是 | 下拉选择已维护的供应商 |
| 账单文件 | 是 | 上传按模板整理好的**标准账单**文件 |

**做完会怎样**：弹窗提示「确认后将在『对账单列表』生成一条草稿状态的对账单数据」。**只落账单明细，不写对账明细底表**——底表的匹配和占用要到详情页点「开始对账」才发生。

**注意**：

- **上传的是标准账单，不是供应商原始账单**。整理这一步在系统外完成——**目前系统只能读模板格式，还不能直接解析供应商的原始账单**；原始文件直接传上来，解析结果必然是错的。
- **供应商一定不能选错**。对账时系统是按「本单供应商 + 系统ID + 费用项 + 币种」去匹配底表的，供应商选错会导致整单匹配不上——要么大量判成「供应商不一致」，要么全部新建记录判成「成本系统无单据」，整张单白做。
- 上传的这份文件会作为本单的「标准账单」显示在详情页，草稿态下还能覆盖替换（见 2.2）。
- **一个文件只能导一个账单类型**。模板里填了多个类型的 sheet，只有排在**前面**那个有内容的会被读进来，其余**直接忽略、不提示**。要导两个类型就分两次导；同一文件里多填的类型不会报错，只会静默丢掉。
- 导入成功不代表数据对了。文件里的单号能不能在成本系统里查到，要等开始对账才见分晓。

## 2.2 核对并补全账单头信息

**什么时候做**：导入之后、推进到待对账之前。

**在哪做**：点列表 ID 进对账单详情页，基础信息区。

**可改哪些**：只有草稿态能改，且只有这几个字段——

| 字段 | 说明 |
| --- | --- |
| 账单日期 | 供应商出账日期，取自文件，可手动修正 |
| 账单周期 | 账单覆盖的时间范围（含开始、结束时间），可修正 |
| 会计期间 | 财务核算对应的月份，取自文件或按账单日期推导，可修正 |
| 标准账单 | 导入时上传的那份文件；草稿态下可覆盖上传 / 替换，页面显示上传状态与导入结果 |
| 备注 | 本单的业务备注（单值），可编辑随单保存 |

其余字段（供应商、供应商账单ID、账单类型、金额等）来自账单文件，不可改。

**怎么做**：两个动作，分工完全不同——

| 动作 | 在哪 | 做什么 | 会不会推进状态 |
| --- | --- | --- | --- |
| 编辑 / 保存 | 基础信息区右下角「编辑」→ 出现「取消」「保存」 | 只把改的内容存下来 | **不会**，仍是草稿 |
| 确认 | 「金额汇总」标题栏右侧的操作区「确认」 | 把单子推进到【待对账】 | **会** |

**做完会怎样**：点「保存」后退回只读草稿态，可以放着不动；点「确认」后状态变【待对账】，基础信息区转为只读。

**注意**：

- **「保存」不等于「确认」**。这是最容易踩的一步：改完点保存以为推进了，实际还停在草稿，后面永远等不到单子可对账。
- **不必先进编辑模式才能确认**。只读草稿态下直接点「确认」就能推进。
- **确认之后，这些字段就再也改不了**。待对账阶段没有退回草稿的路径——「取消对账」只能从对账中退回待对账，回来仍是只读。真要改，只能删单重导。所以**点「确认」之前，把会计期间、账单日期核对清楚**。

## 2.3 删掉导错的草稿

**什么时候做**：导错文件、供应商选错、重复导入。

**在哪做**：列表勾选后「删除」，支持批量。

**适用状态**：草稿、待对账。这两种状态还没进入正式对账流程，可以直接删。

**注意**：

- **进了【对账中】就删不掉**。底表已被占用，必须先「取消对账」退回待对账，才能删。
- 删之前确认这张单确实没用——**重复导入最容易删错**，删掉之后只能重新导入。
