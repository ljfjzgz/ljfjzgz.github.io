# 附录 B 字段速查

> 本附录供查阅：页面上出现的字段叫什么、什么意思、能取什么值。对账明细底表的内部字段不在本附录范围。

---

## B.1 对账单头字段

| 字段 | 含义 | 取值 / 来源 |
| --- | --- | --- |
| ID | 对账单唯一标识 | 系统生成，点它进详情页 |
| 供应商 | 本单归属供应商 | 导入时选择；对账时按它匹配底表 |
| 供应商账单ID | 供应商侧的账单标识 | 解析账单文件取得 |
| 账单类型 | 成本段归属 | 国内转运 / 内地空运 / 香港空运 / 空运卡转 / 国外清关 / 国外转运 / 尾程派送 |
| 状态 | 对账进度 | 草稿 / 待对账 / 对账中 / 已完成 |
| 是否生成账单 | 账单管理数据是否已生成 | 是 / 否；由系统维护，不随状态流转 |
| 账单管理ID | 账单管理侧生成记录的 ID | 生成后回写；未生成为空 |
| 账单日期 | 供应商出账日期 | 解析账单文件；草稿可改 |
| 账单周期 | 账单覆盖的时间范围（含开始、结束时间） | 解析账单文件；草稿可改 |
| 会计期间 | 财务核算对应月份 | 解析文件或按账单日期推导；草稿可改 |
| 币种 | 本单统一币种 | 解析账单文件；单张单下所有明细共用 |
| 账单金额 | 供应商账单金额合计 | 解析账单文件 |
| 快照计算金额 | 本单有效明细的快照合计 | 汇总明细 |
| 付款金额 | 本单按策略确认后应付合计 | 汇总明细 |
| 开始对账时间 | 待对账 → 对账中的时间 | 开始对账时写入 |
| 完成对账时间 | 对账中 → 已完成的时间 | 完成对账时写入，之后不再变 |
| 标准账单 | 导入时上传的标准账单文件 | 草稿可上传 / 替换；非草稿只读 |
| 备注 | 本单业务备注（单值） | 草稿可编辑；与「备注」标签页里的人工跟进记录是两个独立字段 |
| 创建人 / 创建时间 | 导入操作人与时间 | 系统记录 |

## B.2 对账明细字段

| 字段 | 含义 | 取值 / 说明 |
| --- | --- | --- |
| 明细ID | 对账明细唯一标识 | 系统生成；处理文件里靠它定位行 |
| 账单类型 | 成本段归属 | 本单类型固定 |
| 系统ID | 成本系统内的单号 | 尾程匹配处理号，其余匹配运单号；匹配不到为空 |
| 关联ID | 账单文件里的原始单号 | 与系统ID可能不同 |
| 关联类型 | 关联ID的类型 | 处理号 / 跟踪号 / 运单号 / 提单号 |
| 费用项 | 费用项目 | 下拉只展示本单账单类型所包含的费用项 |
| 费用项编码 | 费用项的编码 | 随费用项带出，导出核对用 |
| 币种 | 金额币种 | 本单统一 |
| 账单金额 | 供应商报的金额 | 导入取得 |
| 快照计算金额 | 开始对账时截取的系统计算成本 | 为空表示无可用系统成本（含币种不一致）；0 是有效值，显示 0 而非空 |
| 计算差异 | 账单金额 − 快照计算金额 | 快照为空或币种不一致时显示为空 |
| 差异类型 | 系统判定结果 | 见 A.1；清账由系统写入 |
| 结算策略 | 本次怎么结 | 6 种可手选 + 清账（系统写入）；另可置「空」 |
| 付款金额 | 按策略带出的应付金额 | 按账单金额支付=账单金额；按系统金额支付=快照计算金额；不支付/清账=0；策略为「空」时全空 |
| 账单明细对比参数 | 账单与系统的参数级对比结果 | 计费重、体积重、是否偏远、计价分区等；差异追因主要靠它 |
| 对账单ID | 所属对账单 | 恒为本单 |
| 作废标记 | 是否从本单剔除 | 正常 / 作废 |
| 明细状态 | 这条记录走到哪一步 | 初始 / 待处理 / 已处理 / 已变更待复核 / 已完成 |

## B.3 枚举速查

| 枚举 | 取值 |
| --- | --- |
| 对账状态 | 草稿 → 待对账 → 对账中 → 已完成（取消对账退回待对账） |
| 明细状态 | 初始 / 待处理 / 已处理 / 已变更待复核 / 已完成 |
| 结算策略（可手选 6 种） | 按账单金额支付+争议、按账单金额支付+不争议、按系统金额支付+争议、按系统金额支付+不争议、不支付+争议、不支付+不争议；另有「清账」仅系统写入、「空」为清空 |
| 差异类型（11 种） | 无差异、金额差异、重量偏差（wb＞cp）、重量偏差（wb＜cp）、历史已对账、费用项无计费、供应商不一致、单据无计费、成本系统无单据、对账币种不一致、清账 |
| 作废标记 | 正常 / 作废 |
| 账单类型（7 种） | 国内转运、内地空运、香港空运、空运卡转、国外清关、国外转运、尾程派送 |
| 计提类型 | 红冲 / 确认 / 暂估 |
