## 三、按钮弹窗设计

### 3.1 审核按钮

**触发条件**：索赔状态为【待审核】时显示

**弹窗字段**：

| 字段名称 | 控件类型 | 必填 | 校验规则                  |
| :------- | :------- | :--- | :------------------------ |
| 运单号   | 文本展示 | -    | 显示当前审核的运单号      |
| 供应商   | 文本展示 | -    | 显示供应商名称            |
| 目标节点 | 文本展示 | -    | 显示成本段（A段/B段/C段） |
| 索赔金额 | 文本展示 | -    | 显示索赔金额              |
| 审核结果 | 单选按钮 | 是   | 选项：通过、驳回          |
| 审核意见 | 文本域   | 条件 | 驳回时必填，至少5个字符   |

**触发逻辑**：

| 审核结果 | 系统操作                                                                               |
| :------- | :------------------------------------------------------------------------------------- |
| 通过     | 更新索赔状态为"索赔中"；记录审核时间和审核人；**触发审核通过时分摊（分摊索赔金额至订单）** |
| 驳回     | 更新索赔状态为"已驳回"；记录审核意见                                                   |

### 3.2 回填确认按钮

**触发条件**：索赔状态为【索赔中】且确认金额为空时显示

**弹窗字段**：

| 字段名称    | 控件类型 | 必填 | 校验规则                                              |
| :---------- | :------- | :--- | :---------------------------------------------------- |
| 运单号      | 文本展示 | -    | 显示当前确认的运单号                                  |
| 供应商      | 文本展示 | -    | 显示供应商名称                                        |
| 索赔金额    | 文本展示 | -    | 显示索赔金额                                          |
| 确认币种    | 下拉选择 | 是   | 标准币种代码（USD、CNY、EUR等），需与原索赔币种一致   |
| 确认金额    | 数字输入 | 是   | ≥0 且 ≤ 索赔金额，最多2位小数                          |
| 确认汇率    | 文本展示 | -    | 系统自动取审核通过时汇率                               |
| 确认金额CNY | 文本展示 | -    | 自动计算：确认金额 × 确认汇率，格式如「CNY 3,480.00」 |
| 确认备注    | 文本域   | 否   | 最多200字符                                           |

**触发逻辑**：

| 场景                      | 系统操作                                           |
| :------------------------ | :------------------------------------------------- |
| 0 ≤ 确认金额 ≤ 索赔金额   | 记录确认信息，状态直接变更为【已完结】 |
| 确认金额 > 索赔金额       | 阻断：「确认金额【A】大于原索赔金额【B】，请核实」 |
| 确认金额已存在            | 阻断：「已有确认金额【A】，不可重复确认」          |

### 3.3 新增按钮

**触发条件**：列表页点击新增按钮

**字段校验规则**：

| 字段名称 | 必填 | 校验规则                                                               |
| :------- | :--- | :--------------------------------------------------------------------- |
| 索赔维度 | 是   | 枚举：按运单、按箱子、按订单；决定数据分摊范围及录入字段展示           |
| 运单号   | 是   | 非空且需在TMS运单表中存在；选择后系统自动带出供应商、目标节点          |
| 箱号     | 条件 | 索赔维度=按箱子时必填，支持录入多个箱号；校验箱子是否属于该运单        |
| 处理号   | 条件 | 索赔维度=按订单时必填，支持录入多个处理号；校验处理号是否属于该运单/箱子 |
| 索赔类型 | -    | 系统展示，根据选择的索赔原因自动带出                                   |
| 索赔原因 | 是   | 非空且需在索赔原因（供应商）配置表存在，下拉选择                       |
| 索赔币种 | 是   | 非空且为标准币种代码（USD、CNY、EUR等），下拉选择                      |
| 索赔金额 | 是   | 非空，大于0，最多2位小数                                               |
| 索赔标准 | 否   | 最多100字符，超长截断                                                  |
| 备注     | 否   | 最多200字符，超长截断                                                  |

**触发逻辑**：

1. **字段展示规则**（根据索赔维度动态展示）：

| 索赔维度 | 展示字段       | 隐藏字段     |
| :------- | :------------- | :----------- |
| 按运单   | 运单号         | 箱号、处理号 |
| 按箱子   | 运单号、箱号   | 处理号       |
| 按订单   | 运单号、处理号 | 箱号         |

2. **录入规则**：
   - **按运单**：只需录入运单号，索赔金额分摊至该运单下全部订单
   - **按箱子**：录入运单号 + 一个或多个箱号，索赔金额分摊至指定箱子下全部订单
   - **按订单**：录入运单号 + 一个或多个处理号，索赔金额分摊至指定处理号

3. **校验规则**：
   - 箱号必须属于所选运单
   - 处理号必须属于所选运单（或所选箱子，如先选箱子）

4. **提交后**：执行全字段校验；校验通过后创建索赔单，状态设为【待审核】；跳转回列表页，提示"新增成功"

### 3.4 红冲按钮

**触发条件**：索赔状态为【已完结】且单据类型为【正常索赔】时显示

**前置校验**：

| 校验项                   | 说明                     |
| :----------------------- | :----------------------- |
| **单据类型 != 红冲索赔** | 红冲单本身不能再被红冲   |
| **红冲单号为空**         | 已红冲的单据不可再次红冲 |
| **索赔状态 = 已完结**    | 仅已完结状态可发起红冲   |

**错误提示**：

- 单据类型不符："红冲索赔单据不可再次红冲"
- 红冲单号不为空："该索赔单已存在红冲记录，请勿重复红冲"
- 索赔状态不符："仅已完结的索赔单可发起红冲"

**弹窗字段**：

| 字段名称 | 控件类型 | 必填 | 校验规则                             |
| :------- | :------- | :--- | :----------------------------------- |
| 索赔单号 | 文本展示 | -    | 显示当前红冲的索赔单号               |
| 运单号   | 文本展示 | -    | 显示运单号                           |
| 供应商   | 文本展示 | -    | 显示供应商名称                       |
| 索赔金额 | 文本展示 | -    | 显示原单索赔金额（红冲单将取相反数） |
| 确认金额 | 文本展示 | -    | 显示原单确认金额（红冲单将取相反数） |

**触发逻辑**：

| 步骤 | 系统动作                                                              |
| :--- | :-------------------------------------------------------------------- |
| 1    | 校验红冲条件（红冲单号为空、状态=已完结）                             |
| 2    | 生成红冲单：索赔金额= -(原单索赔金额)、确认金额待审核通过时系统自动填入、索赔原因=主动红冲、单据类型=红冲索赔 |
| 3    | 红冲单状态设为【待审核】                                              |
| 4    | 回填红冲单号到原索赔单（原单红冲单号字段）                            |
| 5    | 打开红冲单审核弹窗或提示"红冲单生成成功，请审核"                      |

#### 3.4.1 红冲单状态流转

| 红冲单状态 | 触发条件           | 系统动作                                                   |
| :--------- | :----------------- | :--------------------------------------------------------- |
| **待审核** | 主动红冲生成时     | 回填红冲单号到原索赔单                                     |
| **索赔中** | 审核通过           | 系统自动填入确认金额=-(原单确认金额)；状态直接流转至【已完结】 |
| **已驳回** | 审核驳回           | 原索赔单红冲单号保留，需删除红冲单后才能重新发起           |
| **已完结** | 审核通过后 | 红冲流程结束，数据归档                   |

状态机：

```
待审核 → 索赔中 → 已完结
    ↓
  已驳回
```

#### 3.4.2 红冲单删除规则

| 状态       | 是否可删除 | 删除后系统动作                                 |
| :--------- | :--------- | :--------------------------------------------- |
| **待审核** | 可删除     | 清空原索赔单的红冲单号字段，原单可重新发起红冲 |
| **已驳回** | 可删除     | 清空原索赔单的红冲单号字段，原单可重新发起红冲 |
| **索赔中** | 不可删除   | -                                              |
| **已完结** | 不可删除   | -                                              |

#### 3.4.3 红冲单生成规则

| 字段     | 生成规则                                                          |
| :------- | :---------------------------------------------------------------- |
| 运单号   | 与原运单号一致                                                    |
| 单据类型 | 红冲索赔                                                          |

### 4.3 分摊明细区

#### 4.3.1 分摊时机与流程

分摊一般至少发生**两次**，均以计费重占比为权重：

```
审核通过 ──→ 【审核通过时分摊】
              ① 拉取当前计费重（按索赔维度确定范围）
              ② 计算各处理号计费重占比
              ③ 分摊索赔金额 → 写入「索赔原币金额」「索赔CNY金额」
              ④ 分摊状态 → 「已分摊」

确认回填 ──→ 【确认回填时分摊】
              ① 重新拉取当前参与分摊的订单及计费重（应对包裹剔除/新增/计费重修正等变动）
              ② 根据最新订单列表重新计算各处理号计费重占比
              ③ 重新分摊索赔金额 → 覆盖「索赔原币金额」「索赔CNY金额」（订单条数可能变动，新增订单补入分摊、退出订单标记已移除）
              ④ 分摊确认金额 → 写入「确认原币金额」「确认CNY金额」
              ⑤ 分摊状态保持「已分摊」
```

| 对比项 | 审核通过时分摊 | 确认回填时分摊 |
| :--- | :--- | :--- |
| 触发时机 | 审核通过 | 确认金额回填后 |
| 计费重来源 | 拉取当前TMS计费重 | **重新**拉取当前TMS计费重 |
| 占比计算 | 新算 | **重新算** |
| 索赔金额列 | 写入 | **覆盖**（应对包裹变动） |
| 确认金额列 | — | 写入 |

> **设计理由**：审核通过到确认回填之间可能间隔数日，期间运单下包裹可能被业务剔除、计费重修正等。确认回填时重新拉取计费重并重算占比，确保分摊数据始终与实际运单结构一致。

#### 4.3.2 明细表格（UI展示，9列）

三个索赔维度共用同一套列结构：

| 序号 | 字段名称 | 字段来源 | 计算/说明 |
| :--- | :--- | :--- | :--- |
| 1 | ID | 系统生成 | 分摊记录唯一标识（底表明细主键） |
| 2 | 箱号 | 系统关联 | 处理号所属箱号 |
| 3 | 处理号 | 系统关联 | 运单下的处理号 |
| 4 | 计费重(kg) | 系统关联 | 处理号计费重量，取自TMS |
| 5 | 计费重占比 | 系统计算 | 计算规则见 4.3.3 |
| 6 | 索赔原币金额 | 系统计算 | 索赔金额(原币) × 计费重占比 |
| 7 | 索赔CNY金额 | 系统计算 | 索赔原币金额 × 索赔汇率 |
| 8 | 确认原币金额 | 系统计算 | 确认金额(原币) × 计费重占比（确认金额为空时显示「-」） |
| 9 | 确认CNY金额 | 系统计算 | 确认原币金额 × 确认汇率（确认金额为空时显示「-」） |

#### 4.3.3 计费重占比计算规则

| 索赔维度 | 分子 | 分母 | 示例 |
| :--- | :--- | :--- | :--- |
| 按运单 | 该处理号计费重 | 运单下**全部**处理号总计费重 | 3.2 ÷ 15.0 = 21.3% |
| 按箱子 | 该处理号计费重 | 该索赔单关联箱子下**全部**处理号总计费重 | 关联2箱下全部处理号计费重合计8.0kg，该处理号3.2kg → 3.2 ÷ 8.0 = 40.0% |
| 按订单 | 该处理号计费重 | 该索赔单关联处理号总计费重 | 关联3个处理号计费重合计15.0kg，该处理号3.2kg → 3.2 ÷ 15.0 = 21.3% |

#### 4.3.4 确认回填时分摊完整步骤（场景示例）

> **场景**：运单 WY001 审核通过时含 3 个处理号（分属箱A/B/C，计费重各 3/4/3kg），索赔金额 USD 500。确认回填前，箱B下处理号被业务剔除。

| 步骤 | 操作 | 结果 |
| :--- | :--- | :--- |
| ① 拉取订单及计费重 | 重新查 TMS，仅剩处理号A(3kg)+C(3kg)，处理号B已退出 | 总计费重 6.0kg，参与分摊处理号变为2条 |
| ② 重新计算占比 | A: 3/6=50%，C: 3/6=50% | 处理号B退出分摊 |
| ③ 覆盖索赔金额 | 索赔 USD 500 × 50% | A: USD 250 / C: USD 250（处理号B分摊记录标记已移除） |
| ④ 覆盖索赔CNY | USD 250 × 7.25 | A: ¥1,812.50 / C: ¥1,812.50 |
| ⑤ 分摊确认金额 | 确认 USD 480 × 50% | A: USD 240 / C: USD 240 |
| ⑥ 分摊确认CNY | USD 240 × 7.25 | A: ¥1,740.00 / C: ¥1,740.00 |
