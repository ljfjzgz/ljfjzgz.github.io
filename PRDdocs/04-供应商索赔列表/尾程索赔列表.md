## 三、按钮与操作

### 3.1 顶部操作按钮

| 按钮         | 功能说明                                         | 交互说明                                    |
| :----------- | :----------------------------------------------- | :------------------------------------------ |
| **新增**     | 打开新增页面，单条录入索赔数据                   | 点击后跳转新增页                            |
| **批量审核** | 基于当前查询条件，批量将待审核单据审核通过或驳回 | 校验后弹出确认弹窗，详见第4.1.2节           |

> **导入入口**：导入功能通过独立导入页面操作，详见 [尾程索赔导入](../02-数据导入/尾程索赔导入.md)

### 3.2 行内操作按钮

#### 3.2.1 根据索赔状态展示操作

## 四、按钮弹窗设计

### 4.1 顶部操作按钮

#### 4.1.1 新增按钮

**触发条件**：列表页点击新增按钮

**字段校验规则**：

| 字段名称 | 必填 | 校验规则                                                             |
| :------- | :--- | :------------------------------------------------------------------- |
| 处理号   | 是   | 非空且需在OMS订单表中存在；选择后系统自动带出产品代码、渠道代码、目的国 |
| 索赔类型 | -    | 系统展示，根据选择的索赔原因自动带出                                 |
| 索赔原因 | 是   | 非空且需在索赔原因（供应商）配置表存在，下拉选择                     |
| 索赔币种 | 是   | 非空且为标准币种代码（USD、CNY、EUR等），下拉选择                    |
| 索赔金额 | 是   | 非空，大于0，最多2位小数                                             |
| 索赔标准 | 否   | 最多100字符，超长截断                                                |
| 备注     | 否   | 最多200字符，超长截断                                                |

**触发逻辑**：

1. **处理号选择后**：系统自动带出产品代码、渠道代码、目的国
2. **提交后**：执行全字段校验；校验通过后创建索赔单，状态设为【待审核】；跳转回列表页，提示"新增成功"

#### 4.1.2 批量审核按钮

**触发条件**：列表页顶部工具栏展示，始终显示

**校验条件**：

| 校验项            | 不通过时弹窗提示                                                                            |
| ----------------- | ------------------------------------------------------------------------------------------- |
| 索赔状态 = 待审核 | 当前筛选条件下存在N条非待审核的记录，汇总数与实际可审核数不一致。请确认查询条件后重新操作。 |

**操作流程**：

```
1. 用户设置查询条件，点击【批量审核】
2. 系统逐条校验上述条件
3a. 全部通过 → 弹窗确认（记录数、条件摘要、审核结果选择）
3b. 存在不通过 → 弹窗阻断提示
```

#### 4.1.3 批量红冲按钮

**触发条件**：列表页顶部工具栏展示，始终显示

**校验条件**：

| 校验项               | 不通过时弹窗提示                  |
| -------------------- | --------------------------------- |
| 单据类型 != 红冲索赔 | 存在N条红冲索赔单据，无法批量红冲 |
| 红冲单号 IS NULL     | 存在N条已红冲的记录               |
| 索赔状态 = 已完结    | 存在N条非已完结状态的记录         |

**操作流程**：

```
1. 用户设置查询条件，点击【批量红冲】
2. 系统逐条校验上述条件
3a. 全部通过 → 确认弹窗 → 批量生成红冲单（红冲单生成规则同单条，详见第5.3节）
3b. 存在不通过 → 弹窗阻断提示
```

> **与单条红冲的区别**：批量红冲为逐单批量处理，逻辑与单条红冲完全一致，不涉及表单填写，处理完成后统跳提示"批量红冲成功"。

## 五、红冲索赔业务逻辑

### 5.1 红冲类型

| 红冲类型     | 触发方式 | 触发条件                     | 审核方式   |
| :----------- | :------- | :--------------------------- | :--------- |
| **主动红冲** | 人工单条 | 运营点击行内【红冲】按钮发起 | 需人工审核 |

### 5.2 前置条件校验

**红冲按钮可用条件**（需同时满足）：

| 校验项               | 说明                     |
| :------------------- | :----------------------- |
| 单据类型 != 红冲索赔 | 红冲单本身不能再被红冲   |
| 红冲单号 IS NULL     | 已红冲的单据不可再次红冲 |
| 索赔状态 = 已完结    | 仅已完结状态可发起红冲   |

**错误提示**：

| 场景           | 提示文案                               |
| :------------- | :------------------------------------- |
| 单据类型不符   | "红冲索赔单据不可再次红冲"             |
| 红冲单号不为空 | "该索赔单已存在红冲记录，请勿重复红冲" |
| 索赔状态不符   | "仅已完结的索赔单可发起红冲"           |

### 5.3 红冲单生成规则

| 字段     | 生成规则           |
| :------- | :----------------- |
| 处理号   | 与原处理号一致     |
| 单据类型 | 红冲索赔           |
| 索赔类型 | 红冲索赔（固定值） |
| 索赔原因 | 主动红冲（固定值） |
| 索赔金额 | -(原单索赔金额)                             |
| 索赔汇率 | 复制原单索赔汇率（= 原索赔单索赔汇率），确保红冲CNY = -原单CNY |
| 确认金额 | 审核通过时系统自动填入（= -(原单确认金额)） |
| 确认汇率 | 复制原单确认汇率（= 原索赔单确认汇率）       |
| 索赔状态 | 待审核                   |

### 5.4 回填时机

**生成红冲单时立即回填红冲单号到原索赔单**：

```
生成红冲单（状态=待审核）
    ↓
立即执行：UPDATE 原索赔单 SET 红冲单号 = '红冲单ID' WHERE 处理号 = '原处理号'
```

### 5.5 红冲单状态流转

| 红冲单状态 | 触发条件           | 系统动作                                                   |
| :--------- | :----------------- | :--------------------------------------------------------- |
| **待审核** | 主动红冲生成时     | 回填红冲单号到原索赔单                                     |
| **索赔中** | 审核通过           | 系统自动填入确认金额=-(原单确认金额)，确认汇率同步复制原单确认汇率；复制原单索赔记录逐行取负写入底表（不再重新分摊）；状态直接流转至【已完结】 |
| **已驳回** | 审核驳回           | 原索赔单红冲单号保留，需删除红冲单后才能重新发起           |
| **已完结** | 审核通过后 | 红冲流程结束，数据归档                   |

状态机：

```
待审核 → 索赔中 → 已完结
    ↓
  已驳回
```

### 5.6 红冲单删除规则

| 状态       | 是否可删除 | 删除后系统动作                                 |
| :--------- | :--------- | :--------------------------------------------- |
| **待审核** | 可删除     | 清空原索赔单的红冲单号字段，原单可重新发起红冲 |
| **已驳回** | 可删除     | 清空原索赔单的红冲单号字段，原单可重新发起红冲 |
| **索赔中** | 不可删除   | -                                              |
| **已完结** | 不可删除   | -                                              |

### 5.7 列表展示

**原索赔单（已红冲）**：

- 红冲单号字段显示关联的红冲单号（可点击跳转）

**红冲单**：

- 单据类型显示"红冲索赔"（标签样式）
- 索赔类型显示"红冲索赔"
- 索赔原因显示"主动红冲"
- 索赔金额显示为**红色负数**（如：-USD 50.00）
