## 二、权限说明

### 2.1 角色职责划分

| 角色 | 权限范围 | 说明 |
|------|---------|------|
| **客服** | 数据录入与查询 | 可查看、新增、编辑、删除、导入、导出数据 |
| **运营** | 全流程管理 | 包含客服所有权限 + 审核、申诉管理、回填确认、红冲操作 |

### 2.2 关键权限说明

| 权限点 | 说明 | PRD 出处 |
|--------|------|----------|
| **审核** | 审核赔付/索赔单，决定是否通过或驳回 | 小包§4.2.1、干线索赔§3.1、尾程索赔§4.2.1 |
| **批量审核** | 根据查询条件批量审核待审核单据 | 小包§4.1.2、尾程索赔§4.1.2 |
| **回填申诉** | 仅小包赔付KPI扣罚类型，回填申诉结果（申诉成功/失败） | 小包§4.2.2 |
| **回填确认** | 供应商索赔确认金额录入，自动推送成本系统 | 干线索赔§3.2、尾程索赔§4.2.2 |
| **红冲** | 冲销已完结的赔付/索赔单，生成红冲单 | 小包§5、干线索赔§3.4、尾程索赔§4.2.3 |
| **批量红冲** | 根据查询条件批量对已完结单据发起红冲 | 小包§4.1.3、尾程索赔§4.1.3 |
| **导入** | 通过独立导入页面上传 Excel 批量新增或回填数据 | 赔付导入、尾程导入 |
| **下载分摊明细CSV** | 干线索赔详情页导出分摊明细为CSV | 干线索赔§4.3.5 |

### 2.3 数据权限说明

- **可见范围**：客服和运营均可查看所有数据
- **操作限制**：按状态控制按钮可用性（如仅待审核状态可审核）
- **字段权限**：所有字段对有权限角色可见
