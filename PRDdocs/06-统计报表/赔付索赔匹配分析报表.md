# 赔付索赔匹配分析报表

> **报表用途**：分析订单维度赔付与索赔的匹配情况，识别有赔付无索赔、有索赔无赔付两类异常场景
>
> **数据来源**：订单赔付索赔底表
>
> **统计逻辑**：直接按底表的【匹配状态】字段分组统计
>
> **筛选说明**：本报表**不设时间筛选**，始终统计全部历史数据。因为两类异常场景需要持续监控跟进，按时间筛选可能导致遗漏未处理的旧记录。异常订单处理完毕后可自然从统计结果中消失。

---

## 一、报表字段

| 序号 | 字段名称            | 字段类型      | 计算逻辑                              | 字段说明                     |
| ---- | ------------------- | ------------- | ------------------------------------- | ---------------------------- |
| 1    | 统计维度            | String        | 枚举值                                | 区分两类异常匹配情况           |
| 2    | 订单数量            | Integer       | COUNT(处理号)                         | 该维度下的订单笔数           |
| 3    | 赔付金额CNY         | Decimal(18,2) | SUM(赔付金额CNY)                      | 客户赔付总金额               |
| 4    | 申诉金额CNY         | Decimal(18,2) | SUM(申诉金额CNY)                      | 申诉成功总金额               |
| 5    | 净赔付金额CNY       | Decimal(18,2) | SUM(赔付金额CNY) - SUM(申诉金额CNY)   | 公司实际承担损失（新口径）   |
| 6    | 索赔金额CNY         | Decimal(18,2) | SUM(索赔金额CNY)                      | 向供应商索赔总金额           |
| 7    | 确认金额CNY         | Decimal(18,2) | SUM(确认金额CNY)                      | 供应商确认赔付总金额         |
| 8    | 赔付索赔差异CNY     | Decimal(18,2) | SUM(赔付金额CNY) - SUM(确认金额CNY)   | 与底表公式一致，客户视角净损失/收益 |

---

## 二、统计维度定义

直接按底表【匹配状态】字段分组统计：

| 统计维度         | 分组条件                  | 业务说明                                                   |
| ---------------- | ------------------------- | ---------------------------------------------------------- |
| **有赔付无索赔** | 匹配状态 = '有赔付无索赔' | 已赔付客户但未向供应商发起索赔，存在漏索赔风险             |
| **有索赔无赔付** | 匹配状态 = '有索赔无赔付' | 已向供应商索赔但无客户赔付，可能为供应商责任索赔或数据异常 |

## 六、业务关注点

| 统计维度     | 关注指标                   | 建议动作                                         |
| ------------ | -------------------------- | ------------------------------------------------ |
| 有赔付无索赔 | 订单数量、赔付金额 | 核查是否漏索赔，补充发起供应商索赔 |
| 有索赔无赔付 | 订单数量、确认金额         | 核查索赔合理性，是否存在虚假索赔                 |
