## 三、导入功能

### 3.1 功能位置

在赔付原因配置列表页面顶部工具栏，新增**导入**按钮。

### 3.2 导入流程

点击导入按钮后选择.xlsx文件，系统解析文件并展示导入预览弹窗，用户确认后执行批量导入，最后返回导入结果（成功/失败数量）。

### 3.3 导入文件格式要求

| 字段名       | 类型   | 必填 | 说明                     | 示例值       |
|--------------|--------|------|--------------------------|--------------|
| 各段分类     | 文本   | 是   | A段/B段/C段/D段/BCD段    | A段          |
| 赔付类型     | 文本   | 是   | 异常赔付/KPI扣罚         | 异常赔付     |
| 赔付原因     | 文本   | 是   | 赔付原因描述             | 司机丢件     |
| 索赔类型     | 文本   | 否   | 丢件/延误出库/延误退件等 | 丢件         |
| 责任划分     | 文本   | 是   | 调度/操作/产品/客服等    | 调度         |
| 内外责任划分 | 文本   | 是   | 内部/外部                | 内部         |
| 备注         | 文本   | 否   | 备注说明                 | 司机提货丢件 |

### 3.4 数据校验规则

| 校验项               | 规则                                                                 | 错误提示                     |
|----------------------|----------------------------------------------------------------------|------------------------------|
| 文件格式             | 仅支持.xlsx格式                                                      | 文件格式错误，请上传.xlsx文件 |
| 必填字段非空         | 各段分类、赔付类型、赔付原因、责任划分、内外责任划分不能为空            | 第X行：[字段名]不能为空       |
| 各段分类合法性       | 必须为A段/B段/C段/D段/BCD段                                          | 第X行：各段分类值无效         |
| 赔付类型合法性       | 必须为异常赔付/KPI扣罚                                                | 第X行：赔付类型值无效         |
| 内外责任划分合法性   | 必须为内部/外部                                                      | 第X行：内外责任划分值无效     |
| 责任划分合法性       | 必须为系统预设值（调度/操作/产品/客服/空运/关务/IT/尾程/海外转运）    | 第X行：责任划分值无效         |
| 重复数据处理         | 同一赔付原因视为重复记录，导入时执行更新操作                           | 第X行：已存在，将执行更新     |

### 3.5 导入预览弹窗

| 区域         | 内容说明                                                                 |
|--------------|--------------------------------------------------------------------------|
| 标题         | 导入赔付原因配置 - 预览                                                  |
| 数据表格     | 展示解析后的所有记录，每行显示：序号、各段分类、赔付类型、赔付原因、状态   |
| 状态标识     | 绿色勾选=校验通过；红色叉号=校验失败（悬停显示失败原因）                  |
| 操作按钮     | 全部导入（仅当有校验通过记录时可用）、下载模板、取消                      |

### 3.6 导入结果处理

| 结果类型     | 处理方式                                                                 |
|--------------|--------------------------------------------------------------------------|
| 全部成功     | 提示"导入成功，共导入X条记录"，刷新列表页面                               |
| 部分成功     | 提示"导入完成，成功X条，失败Y条"，可下载失败明细Excel文件                 |
| 全部失败     | 提示"导入失败，所有记录均未通过校验"，显示失败原因汇总                     |

### 3.7 导入模板

系统提供标准导入模板下载，模板包含：
- 表头行（中文字段名）
- 示例数据行（便于用户理解格式）
- 隐藏列说明（各字段的取值范围）
