> **文档说明**：小包业务客户赔付列表页面的产品需求文档

## 一、页面概述

### 1.1 页面定位

小包赔付客户列表是客户赔付业务的核心管理页面，提供赔付数据的查询、审核、申诉管理、批量操作等功能。

### 1.2 多币种金额汇总

列表上方增加一行文本展示，基于当前查询条件实时汇总，不随翻页变化：

```
赔付原币金额汇总：CNY 120,500.00 ; GBP 1,230.00 ; USD 3,450.00
```

> **说明**：仅展示原币金额的分币种汇总，不做CNY汇率折算合计；记录数看分页条即可。

## 三、按钮与操作

### 3.1 顶部操作按钮

| 按钮         | 功能说明                           | 交互说明                    |
| ------------ | ---------------------------------- | --------------------------- |
| **新增**     | 打开新增页面，单条录入赔付数据     | 点击后跳转新增页            |
| **根据查询条件批量审核** | 基于当前查询条件批量审核赔付数据   | 见第4.1.2节批量审核按钮设计 |
| **根据查询条件批量红冲** | 基于当前查询条件批量红冲已完结赔付 | 见第4.1.3节批量红冲按钮设计 |
| **导出**     | 导出当前筛选结果                   | 点击后下载Excel文件         |

> **导入入口**：导入功能通过独立导入页面操作，详见 [赔付客户导入](../02-数据导入/赔付客户导入.md)

### 3.2 行内操作按钮

#### 3.2.1 根据赔付状态展示操作（正常赔付单）

| 赔付状态   | 展示操作             | 操作说明                                                               |
| ---------- | -------------------- | ---------------------------------------------------------------------- |
| **待审核** | [审核] [编辑] [删除] | 审核：打开审核弹窗<br>编辑：修改赔付数据<br>删除：物理删除，需二次确认 |
| **已审核** | -                    | 审核通过，等待财务返回ID；KPI扣罚类型可回填申诉（见3.2.2节）           |
| **已驳回** | [编辑] [删除]        | 编辑：修改赔付数据，确认后状态变为待审核<br>删除：物理删除，需二次确认 |
| **已完结** | [红冲]               | 红冲：打开红冲弹窗，发起红冲（需满足红冲条件）                         |

#### 3.2.2 根据申诉状态展示操作（仅KPI扣罚类型）

| 申诉状态     | 展示操作   | 操作说明                                                                            |
| ------------ | ---------- | ----------------------------------------------------------------------------------- |
| **申诉中**   | [回填申诉] | 回填申诉：打开申诉结果回填弹窗（需同时满足赔付状态=已完结，否则提示等待财务返回ID） |
| **申诉成功** | -          | 已生成红冲单，申诉流程结束                                                          |
| **申诉失败** | -          | 申诉失败，申诉流程结束                                                              |

**说明**：

- 申诉状态是独立字段，仅对KPI扣罚类型有效
- 异常赔付类型没有申诉状态
- KPI扣罚类型审核通过后，系统自动将申诉状态设为"申诉中"
- 申诉流程为独立分支流程，不影响赔付状态流转

#### 3.2.3 根据单据类型展示操作（红冲赔付单）

| 单据类型     | 赔付状态 | 展示操作      | 操作说明                                                                       |
| ------------ | -------- | ------------- | ------------------------------------------------------------------------------ |
| **红冲赔付** | 待审核   | [审核] [删除] | 审核：打开红冲单审核弹窗<br>删除：物理删除，需二次确认，删除后清空原单红冲单号 |
| **红冲赔付** | 已审核   | -             | 审核通过，等待财务返回ID                                                       |
| **红冲赔付** | 已驳回   | [删除]        | 删除：物理删除，需二次确认，删除后清空原单红冲单号，原单可重新发起红冲         |

### 3.3 行内操作逻辑

所有行内操作均为单条处理。

> 批量操作（根据查询条件批量审核、根据查询条件批量红冲、批量回填申诉）通过顶部按钮或独立导入页面完成。

## 四、按钮弹窗设计

### 4.1 顶部操作按钮

#### 4.1.1 新增按钮

**触发条件**：列表页点击新增按钮

**字段校验规则**：

| 字段名称 | 必填 | 校验规则                                                    |
| -------- | ---- | ----------------------------------------------------------- |
| 处理号   | 是   | 非空且需在OMS订单表中存在                                   |
| 赔付原因 | 是   | 非空且需在赔付原因（客户）配置表存在，下拉选择              |
| 赔付币种 | 是   | 非空且为标准币种代码（USD、CNY、EUR等），下拉选择           |
| 赔付金额 | 是   | 非空，大于0，最多2位小数；与币种组合展示为「USD 50.00」格式 |
| 赔偿标准 | 否   | 最多100字符，超长截断                                       |
| 备注     | 否   | 最多200字符，超长截断                                       |

**触发逻辑**：执行全字段校验；校验通过后创建赔付单，状态设为【待审核】；跳转回列表页，提示"新增成功"

**组合唯一性校验说明**（同导入逻辑）：

```
查询条件：处理号 = 输入值 AND 赔付原因 = 选择值
```

| 场景                                     | 结果        | 说明                                         |
| ---------------------------------------- | ----------- | -------------------------------------------- |
| 记录不存在                               | ✅ 允许提交 | -                                            |
| 记录存在，红冲单号为空                   | ❌ 阻断提交 | 该订单此原因已有未完结赔付，且未被红冲       |
| 记录存在，红冲单号有值，红冲原因为「主动红冲」 | ✅ 允许提交 | 主动红冲视为运营主动撤销，可重新赔付         |
| 记录存在，红冲单号有值，红冲原因为「申诉红冲」 | ❌ 阻断提交 | 申诉红冲为差额冲销，原赔付事实成立，不支持重新赔付 |

#### 4.1.2 根据查询条件批量审核按钮

**触发条件**：列表页顶部工具栏展示，始终显示

**校验条件**：

| 校验项            | 不通过时弹窗提示                                                                            |
| ----------------- | ------------------------------------------------------------------------------------------- |
| 赔付状态 = 待审核 | 当前筛选条件下存在N条非待审核的记录，汇总数与实际可审核数不一致。请确认查询条件后重新操作。 |

**操作流程**：

```
1. 用户设置查询条件，点击【根据查询条件批量审核】
2. 系统逐条校验上述条件
3a. 全部通过 → 弹窗确认：
    · 显示校验通过的记录数
    · 显示筛选条件摘要
    · 审核结果：通过/驳回（单选）
    · 审核原因：驳回时必填
    · 用户确认后批量执行（审核逻辑同单条）
3b. 存在不通过 → 弹窗阻断提示
```

#### 4.1.3 根据查询条件批量红冲按钮

**触发条件**：列表页顶部工具栏展示，始终显示

**校验条件**：

| 校验项               | 不通过时弹窗提示                                               |
| -------------------- | -------------------------------------------------------------- |
| 单据类型 != 红冲赔付 | 当前筛选条件下存在N条【红冲赔付】单据，无法根据查询条件批量红冲            |
| 赔付状态 = 已完结    | 当前筛选条件下存在N条非【已完结】状态的记录                    |
| 红冲单号 IS NULL     | 当前筛选条件下存在N条已红冲的记录                              |
| KPI扣罚需申诉失败    | 当前筛选条件下存在N条KPI扣罚类型且申诉状态非【申诉失败】的记录 |

**操作流程**：

```
1. 用户设置查询条件，点击【根据查询条件批量红冲】
2. 系统逐条校验上述条件
3a. 全部通过 → 确认弹窗 → 批量生成红冲单（红冲单生成规则同单条，详见第5.3节）
3b. 存在不通过 → 弹窗阻断提示
4. 用户调整条件后重新操作
```

> **与单条红冲的区别**：根据查询条件批量红冲为逐单批量处理，逻辑与单条红冲完全一致，不涉及表单填写（无红冲说明输入），处理完成后统跳提示"根据查询条件批量红冲成功"。

### 4.2 行内操作按钮

#### 4.2.1 审核按钮

**触发条件**：赔付状态为【待审核】时显示

**弹窗字段**：

| 字段名称 | 控件类型 | 必填 | 校验规则                                                   |
| -------- | -------- | ---- | ---------------------------------------------------------- |
| 处理号   | 文本展示 | -    | 显示当前审核的处理号                                       |
| 客户代码 | 文本展示 | -    | 显示客户代码                                               |
| 赔付类型 | 文本展示 | -    | 显示赔付类型（异常赔付/KPI扣罚），帮助审核人员判断流程分支 |
| 赔付金额 | 文本展示 | -    | 显示赔付金额                                               |
| 审核结果 | 单选按钮 | 是   | 选项：通过、驳回                                           |
| 审核原因 | 文本域   | 条件 | 驳回时必填，至少5个字符                                    |

**触发逻辑**：

| 审核结果 | 系统操作                                                                                          |
| -------- | ------------------------------------------------------------------------------------------------- |
| 通过     | 更新赔付状态为"已审核"；记录审核时间和审核人；异步推送财务系统；KPI扣罚类型更新申诉状态为"申诉中" |
| 驳回     | 更新赔付状态为"已驳回"；记录审核原因                                                              |

#### 4.2.2 回填申诉按钮

**触发条件**：KPI扣罚类型且申诉状态为【申诉中】时显示

**前置校验**：

| 校验项            | 说明                     |
| ----------------- | ------------------------ |
| 赔付状态 = 已完结 | 财务已返回ID才能回填申诉 |

**错误提示**：赔付状态≠已完结时，提示"财务未返回ID，请等待赔付完结后再回填申诉"

**弹窗字段**：

| 字段名称             | 控件类型 | 必填 | 校验规则                                                |
| -------------------- | -------- | ---- | ------------------------------------------------------- |
| 处理号               | 文本展示 | -    | 显示当前申诉的处理号                                    |
| 客户代码             | 文本展示 | -    | 显示客户代码                                            |
| 赔付类型             | 文本展示 | -    | 显示赔付类型（KPI扣罚），确认申诉类型归属               |
| 赔付金额             | 文本展示 | -    | 显示赔付金额                                            |
| 申诉结果             | 单选按钮 | 是   | 选项：申诉成功、申诉失败                                |
| **最终赔付原币金额** | 数字输入 | 条件 | 仅申诉结果=成功时必填，只填数字，币种自动取赔付金额币种 |
| 申诉结果说明         | 文本域   | 条件 | 申诉失败时必填，至少5个字符                             |

**触发逻辑**：

| 申诉结果 | 系统操作                                                                                                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 申诉成功 | 记录最终赔付原币金额到赔付单；计算申诉金额原币=赔付金额-最终赔付原币金额、取审核通过时间汇率计算申诉汇率和申诉金额CNY、生成申诉红冲单（金额= -(申诉金额差额)，非原单全额）、红冲单自动审核通过并推送财务 |
| 申诉失败 | 更新申诉状态为"申诉失败"；记录申诉结果说明；不更新赔付状态（等待财务返回ID后自动完结）                                                                                                                       |

#### 4.2.3 编辑按钮

**触发条件**：赔付状态为【待审核】或【已驳回】时显示

**页面布局**：同新增页面

**字段校验规则**：同新增页面，处理号不可修改

**触发逻辑**：执行全字段校验；校验通过后更新赔付单；状态重置为【待审核】；跳转回列表页，提示"编辑成功"

#### 4.2.4 删除按钮

**触发条件**：赔付状态为【待审核】或【已驳回】时显示

**交互方式**：二次确认弹窗

**触发逻辑**：物理删除赔付单；刷新列表，提示"删除成功"

#### 4.2.5 红冲按钮

**触发条件**：点击行内【红冲】按钮

**弹窗字段**：

| -------- | -------- | ---- | --------------------- |
| 处理号   | 文本展示 | -    | 显示当前红冲的处理号  |
| 赔付原因 | 文本展示 | -    | 显示原单赔付原因      |
| 赔付金额 | 文本展示 | -    | 显示原单赔付金额      |

## 五、红冲按钮逻辑

### 5.1 红冲类型

| 红冲类型     | 触发方式 | 触发条件                                                      | 审核方式     |
| ------------ | -------- | ------------------------------------------------------------- | ------------ |
| **申诉红冲** | 系统自动 | KPI扣罚申诉成功时自动生成，金额=赔付金额-最终赔付金额（差额） | 自动审核通过 |
| **主动红冲** | 人工单条 | 运营点击行内【红冲】按钮发起                                  | 需人工审核   |

### 5.2 前置条件校验

**红冲按钮可用条件**（需同时满足）：

```sql
-- 校验逻辑
WHERE 单据类型 != '红冲赔付'
  AND 赔付状态 = '已完结'
  AND 红冲单号 IS NULL
  AND (赔付类型 = '异常赔付'
       OR (赔付类型 = 'KPI扣罚' AND 申诉状态 = '申诉失败'))
```

| 校验项               | 说明                                   |
| -------------------- | -------------------------------------- |
| 单据类型 != 红冲赔付 | 红冲单本身不能再被红冲                 |
| 赔付状态 = 已完结    | 只有财务返回ID（已完结）的数据才能红冲 |
| 红冲单号 IS NULL     | 已红冲的单据不可再次红冲               |
| KPI扣罚需申诉失败    | KPI扣罚类型需申诉失败后才能主动红冲    |

**错误提示**：

| 场景              | 提示文案                                      |
| ----------------- | --------------------------------------------- |
| 红冲单号不为空    | "该赔付单已红冲，请勿重复操作"                |
| KPI扣罚且申诉中   | "KPI扣罚类型需申诉失败后才能红冲"             |
| KPI扣罚且申诉成功 | "申诉成功的KPI扣罚单已自动红冲，请勿重复操作" |
| 赔付状态不符      | "仅已完结的赔付单可发起红冲"                  |

### 5.3 红冲单生成规则

| 字段     | 生成规则                                                                        |
| -------- | ------------------------------------------------------------------------------- |
| 处理号   | 与原处理号一致（如 `WNBAA0465333020YQ`）                                        |
| 单据类型 | 红冲赔付                                                                        |
| 赔付类型 | 红冲赔付（固定值）                                                              |
| 赔付原因 | 主动红冲：固定为"主动红冲"；申诉红冲：固定为"申诉红冲"                          |
| 赔付金额 | 主动红冲：-原单金额（负数）；申诉红冲：-(赔付金额-最终赔付金额)（差额，非全额） |
| 赔付状态 | 待审核（主动红冲）/ 已审核（申诉红冲）                                          |

### 5.4 回填时机

**生成红冲单时立即回填红冲单号到原赔付单**：

```
生成红冲单（状态=待审核或已审核）
    ↓
立即执行：UPDATE 原赔付单 SET 红冲单号 = '红冲单ID' WHERE 处理号 = '原处理号'
```

### 5.5 红冲单状态流转

| 红冲单状态 | 触发条件                             | 系统动作                                                   |
| ---------- | ------------------------------------ | ---------------------------------------------------------- |
| **待审核** | 主动红冲生成时                       | 回填红冲单号到原赔付单                                     |
| **已审核** | 审核通过（主动）/ 生成即审核（申诉） | 推送财务系统，返回ID后回填财务返回ID；状态流转至【已完结】 |
| **已驳回** | 审核驳回                             | 原赔付单红冲单号保留，需删除红冲单后才能重新发起           |
| **已完结** | 已审核且财务返回ID                   | 红冲流程结束，数据归档                                     |

状态机：

```
待审核 → 已审核 → 已完结
    ↓
  已驳回
```

### 5.6 红冲单删除规则

- **可删除状态**：待审核、已驳回
- **不可删除状态**：已审核（已推送财务）、已完结（财务已返回）
- **删除时操作**：
  1. 物理删除红冲单
  2. 清空原赔付单的红冲单号字段（SET 红冲单号 = NULL）
  3. 原赔付单可重新发起红冲

### 5.7 列表展示

**原赔付单（已红冲）**：

- 红冲单号字段显示关联的红冲单号（可点击跳转）

**红冲单**：

- 单据类型显示"红冲赔付"（标签样式）
- 赔付类型显示"红冲赔付"
- 赔付原因显示"主动红冲"或"申诉红冲"
- 赔付金额显示为**红色负数**（如：-USD 50.00）
