# 索赔导入说明

> **说明**：索赔导入页面为独立页面，供运营使用。页面顶部通过"操作类型"下拉区分不同导入场景，每种操作对应独立的模板格式、校验规则和处理逻辑。

---

## 一、操作类型概览

| 操作类型         | 模板字段                                             | 核心匹配键            | 业务场景                         |
| ---------------- | ---------------------------------------------------- | --------------------- | -------------------------------- |
| **新增尾程索赔** | 处理号、索赔原因、索赔币种、索赔金额、索赔标准、备注 | 处理号+索赔原因（查未红冲记录，存在则阻断，已红冲可重新导入） | 导入新增尾程索赔数据             |
| **批量确认金额** | 处理号、索赔原因、确认金额原币、确认币种、确认备注   | 处理号+索赔原因（查索赔中且未确认记录） | 批量回填供应商确认的索赔赔付金额 |

> **说明**：干线索赔暂不纳入导入，因其录入维度复杂（运单/箱子/订单），保持手动新增。

---

## 二、新增尾程索赔

> 索赔原因需在索赔原因配置表中存在，详见 [索赔原因（供应商）](../01-赔付类型配置/索赔原因（供应商）.md)

### 2.1 模板字段

| 模板列 | 字段名称 | 必填 | 校验规则                                       | 导入后展示                        |
| ------ | -------- | ---- | ---------------------------------------------- | --------------------------------- |
| A      | 处理号   | 是   | 非空且需在OMS订单表中存在                     | -                                 |
| B      | 索赔原因 | 是   | 非空且需在索赔原因（供应商）配置表存在，自动带出索赔类型 | -                                 |
| C      | 索赔币种 | 是   | 非空且为标准币种代码（USD、CNY、EUR等）        | 与金额合并展示为「USD 50.00」格式 |
| D      | 索赔金额 | 是   | 非空，大于0，最多2位小数                       | 与币种合并展示为「USD 50.00」格式 |
| E      | 索赔标准 | 否   | 最多100字符，超长截断                          | -                                 |
| F      | 备注     | 否   | 最多200字符，超长截断                          | -                                 |

### 2.2 组合唯一性校验

```
查询条件：处理号 = 导入值 AND 索赔原因 = 导入值 AND 红冲单号 IS NULL
```

| 场景             | 结果        | 说明                       |
| ---------------- | ----------- | -------------------------- |
| 记录存在         | ❌ 阻断导入 | 该订单此原因已有未完结索赔 |
| 记录不存在       | ✅ 允许导入 | -                          |
| 记录存在但已红冲 | ✅ 允许导入 | 红冲单号有值视为已冲销     |

> **错误提示**：处理号【{处理号}】已存在索赔原因【{索赔原因}】的未完结索赔记录，请勿重复导入。如需重新索赔，请先红冲原索赔单。

### 2.3 导入后处理

- 校验通过的数据立即创建索赔单，状态为【待审核】
- 系统根据处理号自动带出产品代码、渠道代码、目的国
- 导入完成后显示结果汇总（成功X条/失败Y条），支持下载失败提示文档（格式见下方）

### 2.4 失败提示文档格式

| 处理号  | 索赔原因 | 索赔币种 | 索赔金额 | 索赔标准       | 备注 | **失败原因**                                               |
| ------- | -------- | -------- | -------- | -------------- | ---- | ---------------------------------------------------------- |
| OD001   | 尾程丢失 | USD      | 50.00    | 按实际损失赔付 |      | 处理号【OD001】已存在索赔原因【尾程丢失】的未完结记录      |
| OD002   |          | USD      | 30.00    |                |      | 索赔原因不能为空                                           |
| INVALID | 尾程丢失 | CNY      | 100.00   |                |      | 处理号【INVALID】在OMS订单表中不存在                      |
| OD003   | 无效原因 | EUR      | 25.50    |                |      | 索赔原因【无效原因】不存在，请核对后重新填写               |
| OD004   | 派送超时 | KFC      | 40.00    |                |      | 索赔币种【KFC】无效，请使用标准币种代码（如USD、CNY、EUR） |

## 三、批量确认金额

### 3.1 模板字段

| 模板列 | 字段名称     | 必填 | 校验规则                                                       | 导入后展示                        |
| ------ | ------------ | ---- | -------------------------------------------------------------- | --------------------------------- |
| A      | **处理号**   | 是   | 非空，需在OMS订单表中存在                                       | -                                 |
| B      | **索赔原因** | 是   | 非空，需在索赔原因（供应商）配置表存在                           | -                                 |
| C      | 确认币种     | 是   | 非空，标准币种代码（USD、CNY、EUR等），需与原索赔币种一致        | 与金额合并展示为「USD 50.00」格式 |
| D      | 确认金额原币 | 是   | 非空，≥0，≤ 原索赔金额，最多2位小数                              | 与币种合并展示为「USD 50.00」格式 |
| E      | 确认备注     | 否   | 最多200字符                                                     | -                                 |

### 3.2 匹配与校验

> 匹配键与 [二、2.2 新增尾程索赔](#22-组合唯一性校验) 去重查询同源，但此处增加状态+确认金额校验，业务结果相反。

匹配查询：处理号 = 导入值 AND 索赔原因 = 导入值 AND 红冲单号 IS NULL AND 索赔状态 = 索赔中 AND 确认金额原币 IS NULL

| 结果   | 处理                                 |
| ------ | ------------------------------------ |
| 0 条   | ❌ 按实际原因分类提示（见下方校验表） |
| **1 条** | ✅ 进入前置条件校验                   |

**前置条件校验**：

| 校验项                    | 失败原因                                                     |
| ------------------------- | ------------------------------------------------------------ |
| 索赔状态 = 索赔中         | 处理号【X】+ 索赔原因【Y】当前状态为【Z】，需索赔中才能确认   |
| 红冲单号 IS NULL          | 处理号【X】+ 索赔原因【Y】已红冲（红冲单号【Z】），不可确认  |
| 确认金额原币 IS NULL      | 处理号【X】+ 索赔原因【Y】已有确认金额【A】，不可重复确认     |
| 确认金额 ≥ 0              | 确认金额不能为负数                                            |
| 确认金额 ≤ 索赔金额原币   | 确认金额【A】大于原索赔金额【B】，请核实                       |
| 确认币种 = 索赔币种       | 确认币种【A】与原索赔币种【B】不一致，请核实                   |

### 3.3 导入后处理

- 校验通过的数据，执行以下操作：
  1. 更新索赔单的确认金额、确认币种、确认备注
  2. 系统自动取审核通过时间的成本系统汇率，计算确认汇率、确认金额CNY
  3. 更新索赔确认差异CNY = 索赔金额CNY - 确认金额CNY
  4. 更新索赔状态为【已完结】
- 导入完成后显示结果汇总（成功X条/失败Y条），支持下载失败提示文档（格式同 [2.4](#24-失败提示文档格式)，列结构随模板字段而变化）

| OD001  | 尾程丢失 | USD      | 45.00        |          | 已通过校验                                                       |
| OD002  | 尾程断更 | USD      | 30.00        |          | 当前状态为【待审核】，需索赔中才能确认                             |
